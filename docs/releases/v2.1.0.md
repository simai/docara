# Docara 2.1.0

Release date: 2026-08-26

Docara 2.1.0 adds shared project examples and non-blocking translation
tracking while preserving existing inline examples, fenced code blocks,
locale routing, and Docara 2 project ownership rules.

## Requirements

- PHP 8.2 or newer;
- Composer;
- an existing Docara 2 project or an empty directory for `init`.

## Install or update

For a new engine installation:

```bash
composer require simai/docara:^2.1
```

For an existing Docara 2 engine consumer, update its Composer dependency first.
Then verify and apply the project-owned engine snapshot transaction:

```bash
php /path/to/engine/vendor/bin/docara update --verify --json
php /path/to/engine/vendor/bin/docara update --dry-run --json
# Review the exact plan before applying it.
php /path/to/engine/vendor/bin/docara update --apply=<plan-sha256> --json
php /path/to/engine/vendor/bin/docara build production
php /path/to/engine/vendor/bin/docara verify-static build_production
```

Docara does not overwrite project Markdown, examples, assets, configuration,
translation locks, or the engine consumer's `composer.lock`.

## Reusable examples

Projects may place one shared demonstration in:

```text
examples/utilities/animation-duration/
  index.html
  index.css
  index.js
  assets/
```

and reference it from any locale:

```markdown
:::example {id="utilities/animation-duration"}
:::
```

Only `index.html` is required. Docara creates tabs only for files that exist,
publishes confined assets with `base_url`, records consumers and hashes in
`.docara/examples.json`, and invalidates affected partial builds when a shared
example changes. Existing inline `:::example` blocks remain compatible.

## Translation tracking

Projects can enable report-only translation tracking independently of locale
fallback and missing-page routing. The status command reports current, stale,
missing, unverified, orphaned, structurally mismatched, duplicate, and excluded
records for pages and `lang.json` dictionaries:

```bash
php vendor/bin/docara translations status
php vendor/bin/docara translations status --locale=en --status=stale --json
```

Docara never translates content and status/build never edit authored files.
A reviewed page is accepted through a hash-bound dry-run/apply plan; changing
any input invalidates that plan.

## Interface improvements

- Result and source tabs now use their natural height instead of sharing a
  fixed tall frame.
- Code blocks use the same source-panel styling and copy affordance as Example.
- Top-level navigation can select a section-specific secondary tree.
- Language selection can be presented as a compact icon-triggered menu.
- Hero and step components have improved responsive spacing and alignment.

## Compatibility and rollback

The release is backward compatible within Docara 2. Shared examples and
translation tracking are opt-in. To roll back a project engine snapshot, use
the existing transactional rollback command and rebuild the static output:

```bash
php /path/to/engine/vendor/bin/docara update --rollback=latest
php /path/to/engine/vendor/bin/docara build production
php /path/to/engine/vendor/bin/docara verify-static build_production
```

A successful package or site build is not a public deployment.
