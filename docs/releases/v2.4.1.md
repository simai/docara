# Docara 2.4.1

Docara 2.4.1 is a compatibility correction for the source-backed
documentation tracking introduced in 2.4.0.

Projects may pin an exact neutral Framework documentation contract through
`runtime.framework_registry.documentation_source`. Docara now treats that
project-owned pointer as tracking metadata while preserving strict equality of
the actual bundled Framework runtime. The contract path, schema and SHA-256
remain verified independently before any source entity is read.

No migration is required for projects that do not use
`documentation_tracking`.
