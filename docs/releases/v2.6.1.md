# Docara 2.6.1

Date: 2026-09-02

Docara 2.6.1 is a backward-compatible patch release that updates the
package-owned SIMAI Framework runtime to immutable `v5.6.0`.

## Included

- The accessible Accordion trigger/panel contract.
- Independent sections and `data-sf-accordion-mode="single"`.
- Filled, outline and flush surfaces with token-driven geometry.
- Exact Framework registry and source provenance for documentation tracking.

## Compatibility

Projects pinned to the exact Framework 5.5.0 lock are admitted through the
package compatibility ledger. Project-owned Markdown, examples and settings
are not edited automatically.
