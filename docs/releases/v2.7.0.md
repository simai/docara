# Docara 2.7.0

Date: 2026-09-02

Docara 2.7.0 adds deterministic Example preview placement and updates the
package-owned SIMAI Framework runtime to immutable `v5.6.1`.

## Included

- `preview=auto` is the default for Example blocks. Docara selects inline
  rendering for safe self-contained markup and sandbox rendering for reusable
  examples, scripts, styles and assets.
- Authors can explicitly request `preview=inline` or `preview=sandbox`.
  Unsafe inline requests fail closed instead of silently weakening isolation.
- Build receipts and page inspection expose the requested mode, resolved mode
  and decision reason.
- Sandboxed examples inherit active semantic Framework tokens, root font size,
  theme and direction from the documentation shell.
- Sandboxed Result panels follow their measured content height without a
  nested scrollbar, artificial height cap or width-changing transition.
- SIMAI Framework 5.6.1 supplies corrected Accordion typography, keyboard-only
  visible focus, joined focus geometry and the plus/minus indicator variant.

## Compatibility

- Existing Example blocks require no changes; omitted `preview` resolves
  through the deterministic `auto` policy.
- Project-owned Markdown, examples, settings and locks are never rewritten by
  build, validation or inspection.
- Projects pinned to the exact Framework 5.6.0 lock remain admitted through
  the package compatibility path.
