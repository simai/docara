# Docara 2.7.1

Date: 2026-09-06

Docara 2.7.1 updates its package-owned SIMAI Framework runtime to the exact
UI Core `v5.6.2` and Smart `v5.4.1` releases.

## Included

- Admin Menu grows naturally in ordinary document flow and owns scrolling only
  when its host has a finite height.
- Navigation groups, active routes, keyboard focus and RTL behavior use the
  corrected Framework runtime.
- Context Menu supplies the settings and action surface used by Admin Menu.
- The Loader registry retains all 63 public component rules, including the
  compatibility-backed `file-preview` and `link` entries.

## Compatibility

- Existing Docara projects keep their content, examples and configuration.
- Existing projects pinned to the exact Framework 5.6.1 pair remain admitted;
  new builds use the 5.6.2 pair after their lock is updated normally.
- The public Docara AI contract and CLI surface are unchanged.
