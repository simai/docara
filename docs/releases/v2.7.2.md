# Docara 2.7.2

Date: 2026-09-06

Docara 2.7.2 keeps the exact SIMAI Framework UI Core `v5.6.2` and Smart
`v5.4.1` runtime introduced in 2.7.1 and corrects the full-font fallback used
by isolated Example previews.

## Included

- Admin Menu grows naturally in ordinary document flow and owns scrolling only
  when its host has a finite height.
- Unknown outlined icons opt into the exact local full font individually.
- Icons already present in the package-owned subset keep using that subset even
  when another icon requires the fallback.
- Sandboxed examples remain offline and do not replace all prepared icons with
  an unreachable opaque-origin font URL.

## Compatibility

- Existing Docara projects keep their content, examples and configuration.
- The public Docara AI contract and CLI surface are unchanged.
- Projects pinned to the exact Framework 5.6.1 pair remain admitted; new builds
  use Framework 5.6.2 after their lock is updated normally.
