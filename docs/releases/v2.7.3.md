# Docara 2.7.3

Date: 2026-09-06

Docara 2.7.3 completes the isolated icon fallback introduced in 2.7.2. An
Example preview receives both the package-owned subset and the exact local full
outlined font as transferable font data.

## Included

- Known icons continue to use the small prepared subset.
- Only unknown outlined icons receive `sf-icon-full-font`.
- The full font is fetched once by the parent page and transferred into each
  sandbox as a blob, avoiding opaque-origin font requests.
- Admin Menu examples may use representative navigation icons without network
  access or visible ligature text.

## Compatibility

- Project content, examples and configuration are unchanged by the upgrade.
- The public Docara AI contract and CLI surface are unchanged.
- The Framework runtime remains the exact UI Core `v5.6.2` / Smart `v5.4.1`
  pair.
