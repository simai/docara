# Docara 2.7.4

Date: 2026-09-06

Docara 2.7.4 gives the verified local full-font fallback its own family name.
This prevents Framework component CSS from grouping the valid sandbox blob with
a second, opaque-origin font face that cannot pass CORS.

## Included

- Prepared subset icons remain isolated from full-font icons.
- Unknown outlined icons load from the transferred local blob and receive
  `sf-icon-loaded` only after the font is ready.
- The sandbox performs no full-font network request.
- Admin Menu examples render all navigation icons without ligature text.

## Compatibility

- Project content, examples and configuration are unchanged by the upgrade.
- The public Docara AI contract and CLI surface are unchanged.
- The Framework runtime remains the exact UI Core `v5.6.2` / Smart `v5.4.1`
  pair.
