# Docara 2.7.5

Date: 2026-09-06

Docara 2.7.5 installs transferable local font styles before external Framework
stylesheets inside sandboxed Example previews. This closes the short loading
window in which an opaque-origin iframe could request the Framework WOFF2 and
produce a CORS error before the local subset or fallback became authoritative.

## Included

- Prepared subset and full-font fallback styles are present before external
  component stylesheets load.
- Unknown outlined icons continue to use the transferred local full-font blob.
- Admin Menu examples render without missing icons, ligature text, external font
  requests or browser console errors.
- Dynamic Example sizing and theme/token synchronization are unchanged.

## Compatibility

- Project content, examples and configuration are unchanged by the upgrade.
- The public Docara AI contract and CLI surface are unchanged.
- The Framework runtime remains the exact UI Core `v5.6.2` / Smart `v5.4.1`
  pair.
