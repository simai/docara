# Docara 2.8.0

Date: 2026-09-07

Docara 2.8.0 adds focused reading controls to documentation examples without
changing authored source or coupling projects to a custom page shell.

## Included

- Example surfaces can enter and leave browser fullscreen mode. The complete
  surface remains available there, including the rendered result and source
  tabs.
- Source tabs and standalone code blocks can enable CSS-only soft wrapping.
  Copied source keeps its original bytes and line breaks.
- Wrapping has one persisted preference across all source surfaces and starts
  enabled on narrow screens when no preference has been saved.
- Controls use state-specific icons and localized accessible labels. Pointer
  activation does not leave a visible focus ring; keyboard focus remains
  visible.
- `examples.fullscreen`, `examples.wrap` and `code.wrap` inherit through site,
  section and page configuration. Individual Example blocks may override
  `fullscreen` and `wrap`.

## Compatibility

- Existing projects receive both controls by default and may disable either
  capability through inherited configuration.
- Existing Example markup, preview placement and copied source remain
  compatible.
- The public CLI and package-owned SIMAI Framework runtime are unchanged.
