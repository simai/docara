# Docara 2.8.2

Date: 2026-09-07

Patch release for the Example source toolbar and visual wrapping behavior.

## Fixed

- The fullscreen entry action is shown only on the rendered Result tab. When an
  Example is already fullscreen, the exit action remains available after
  switching to a source tab.
- Enabling soft wrapping now removes the code element's intrinsic
  `max-content` width. Long highlighted lines therefore wrap inside the visible
  source area instead of being clipped behind hidden horizontal overflow.

## Compatibility

- Authored Example markup, configuration fields and copied source bytes are
  unchanged.
- Fullscreen and wrap availability continue to inherit through the existing
  site, section, page and per-block settings.
