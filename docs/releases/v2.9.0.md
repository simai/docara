# Docara 2.9.0

Date: 2026-09-10

Minor release that binds Docara to the completed SIMAI Framework 5 foundation
contract.

## Added

- Exact generated Framework contract and documentation-source projections are
  included in both the package documentation site and new portable projects.
- Component styles now bring their local font or image dependencies into the
  immutable runtime projection.
- Docara resolves and projects the finite JavaScript chunks required for its
  supported syntax-highlighting languages from the exact Framework entrypoint.

## Changed

- The bundled pair is SIMAI UI Core 5.7.0 and SIMAI UI Smart 5.5.0.
- Server-side utility planning matches Loader rules against whole class tokens,
  including escaped responsive, state and container-condition forms.
- The accepted foundation plan, decisions and evidence are retained as one
  self-contained strategy packet with portable external references.

## Compatibility

- Existing project-owned content and configuration are not rewritten by a
  normal build. Runtime replacement remains an explicit transactional update.
- Previously published SF5 compatibility names remain available; new projects
  receive the canonical `start`/`end` and Smart spacing contracts through the
  pinned Framework pair.
- No runtime CSS generation is introduced in consumer installations.
