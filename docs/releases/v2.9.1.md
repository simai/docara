# Docara 2.9.1

Date: 2026-09-14

Patch release that publishes the fixes integrated after Docara 2.9.0 and binds
portable sites to the current verified SIMAI Framework pair.

## Changed

- The bundled runtime remains SIMAI UI Core `v5.7.0` and SIMAI UI Smart
  `v5.5.0`, using their Loader-fixed exact commits and regenerated immutable
  projections.
- Framework locks created from the canonical `ui-source` repository identity
  are accepted.

## Fixed

- Large documentation builds release generated Framework CSS while rendering,
  reuse identical preliminary plans and stream the final diagnostic receipt to
  avoid memory exhaustion.
- Navigation disclosure controls follow their labels, Framework icons refresh
  safely, and code and Example headers share the intended alignment.

## Compatibility

- Existing Docara 2.x project content and configuration remain compatible.
- The project-local transactional `upgrade` command remains the supported path
  for promoting dependencies, engine files and verified build output.
- No moving Framework reference or runtime CSS generation is introduced.
