# Components

This section collects the pages of specific Docara components and supported
constructs. If you first want to understand the difference between Markdown,
inline blocks, containers, the Framework and project-owned extensions, open
the [component model](/en/start/component-model/).

## Text and Markdown

These constructs are plain Markdown without components. They are all
described on one page, [Markdown](/en/authoring/markdown/).

| Construct | Purpose |
| --- | --- |
| [Headings and text](/en/authoring/markdown/#headings-and-text) | Headings, paragraphs and text emphasis in plain Markdown |
| [Links and images](/en/authoring/markdown/#links-and-images) | Links to pages and sites, images with alternative text for accessibility |
| [Lists and quotes](/en/authoring/markdown/#lists-and-quotes) | Bulleted and numbered lists and quotes |
| [Checklists and definitions](/en/authoring/markdown/#checklists-and-definitions) | Tasks with checkboxes and terms with definitions |
| [Footnotes and sources](/en/authoring/markdown/#footnotes-and-sources) | Numbered footnotes and a list of sources at the bottom of the page |
| [Table](/en/authoring/markdown/#tables) | A Markdown table; on a narrow screen it scrolls inside itself |

## Content blocks

| Component | Purpose |
| --- | --- |
| [Alert](/en/components/alert/) | A note, tip or warning next to the text |
| [Banner](/en/components/banner/) | A short announcement that applies to the whole page |
| [Details](/en/components/details/) | An extra explanation that the reader opens on demand |
| [Interactive example](/en/components/example/) | A live result next to its source code |
| [Steps](/en/components/steps/) | A numbered instruction of several steps |
| [Tabs](/en/components/tabs/) | Several equivalent options, for example for different systems |
| [File tree](/en/components/tree/) | The structure of the project's folders and files |
| [Backlinks](/en/components/backlinks/) | A list of the site's pages that link to the current one |
