# Content blocks

Blocks that sit in the page text: alerts, steps, tabs, examples and more.

| Component | Purpose |
| --- | --- |
| [Alert](/en/components/blocks/alert/) | A note, tip or warning next to the text |
| [Banner](/en/components/blocks/banner/) | A short announcement that applies to the whole page |
| [Details](/en/components/blocks/details/) | An extra explanation that the reader opens on demand |
| [Interactive example](/en/components/blocks/example/) | A live result next to its source code |
| [Steps](/en/components/blocks/steps/) | A numbered instruction of several steps |
| [Tabs](/en/components/blocks/tabs/) | Several equivalent options, for example for different systems |
| [File tree](/en/components/blocks/tree/) | The structure of the project's folders and files |
| [Backlinks](/en/components/blocks/backlinks/) | A list of the site's pages that link to the current one |

## How to choose

When the reader must not miss a point, use an alert; when an announcement concerns
the whole page, use a banner. Put an ordered procedure into steps and equal options,
such as commands for different systems, into tabs. Hide details that not everyone
needs in a details block. An interactive example shows a live result next to its
source.
