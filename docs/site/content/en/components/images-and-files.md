# Media

Pictures, video, downloadable files and logos.

| Component | Purpose |
| --- | --- |
| [Figure](/en/components/images-and-files/figure/) | An image with a caption and a set aspect ratio |
| [Text with an image](/en/components/images-and-files/media/) | A short explanation next to an image |
| [Embed](/en/components/images-and-files/embed/) | A video, map or external page shown with the reader's consent |
| [Download](/en/components/images-and-files/download/) | A downloadable file with its format, size and checksum |
| [Logos and members](/en/components/images-and-files/logos/) | A row of partner, product or member logos |

## How to choose

A single picture with a caption is a figure, and a short explanation next to a
picture is media with text. Embed a video, a map or an external page only after the
reader agrees, so the site loads nothing foreign without asking. Show a download with
its format, size and checksum, and gather a row of partner or member logos into a
logos block.
