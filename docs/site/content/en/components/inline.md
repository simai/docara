# Inline and actions

Small elements inside a line of text: badges, button links, icons and keys.

| Component | Purpose |
| --- | --- |
| [Badge](/en/components/inline/badge/) | A short status or version label inside the text |
| [Button link](/en/components/inline/button/) | A link styled as a button |
| [Icon](/en/components/inline/icon/) | A Material Symbols icon inside the text and the list of all 3926 icons |
| [Keyboard input](/en/components/inline/kbd/) | A key or a key combination |

## How to choose

These elements sit inside a line of text and do not break the paragraph. A badge
marks a status or a version, a button link leads to the next action, an icon
explains a meaning with a picture, and keyboard input shows a key or a key
combination. A badge is not clickable: to move to another page use a button link.
