# SIMAI Framework

SIMAI Framework components you can put straight into Markdown.

| Component | Purpose |
| --- | --- |
| [SIMAI Framework ui.* components](/en/components/simai-framework/smart-ui/) | The `ui.button` button, the `ui.alert` alert and other Framework elements with parameter checks |

## When to use

SIMAI Framework components are for a Docara site that runs over the SIMAI design
system and must look like the other products. Docara checks every component's
parameters at build time and reports an error before publishing. When a Docara block
already fits, such as an alert or a button link, start with it: it is simpler and
does not depend on the Framework version.
