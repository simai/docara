# Test mode

In test mode the API works the same as in live mode, but no money is
charged, and notifications go only to the test URL.

:::ui.alert
{"type":"warning","variant":"outlined","title":"No money is charged","supporting-text":"Payments with a test key never reach the bank. Replace the key with a live one before launch.","closable":false,"aria-label":"Test mode: no money is charged"}
:::

## Switching to live mode

Create a live key in your dashboard and replace the test key with it in your
store settings.
