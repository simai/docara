# SIMAI Framework delivery errors

Docara ships SIMAI Framework inside its package: styles, scripts, icons,
fonts and component descriptions. The project file
`simai-framework.lock.json` (the `framework_lock` field in `docara.json`)
names the exact version of this delivery. Before the build, Docara checks
every Framework file against the pinned hashes, so the site does not depend
on external servers and does not change by itself. How the file is built is
described on [Framework lock file](/en/reference/framework-lock/).

## What to do in most cases

Almost all codes on this page mean one of two things: the lock file does not
match the delivery in the package, or the package files are damaged.

1. Do not edit `simai-framework.lock.json` by hand.
2. If you recently updated Docara, replace the project lock file with the
   shipped one:

   ```bash
   cp vendor/simai/docara/stubs/portable/simai-framework.lock.json simai-framework.lock.json
   ```

3. Restore the package files from `composer.lock`: delete the
   `vendor/simai/docara` folder and run `composer install`.
4. Run a full build. If the error stays, report it as described on
   [Internal errors](/en/reference/errors/internal/#what-to-do).

## The lock file

| Code | Cause and what to do |
| --- | --- |
| `FRAMEWORK_LOCK_MISSING`, `FRAMEWORK_LOCK_PATH_INVALID` | The file from the `framework_lock` field does not exist. **What to do:** Copy the shipped file as shown above and check the path in `docara.json`. |
| `FRAMEWORK_LOCK_JSON_INVALID` | The lock file is not valid JSON. **What to do:** Restore the file from the project history or replace it with the shipped one. |
| `FRAMEWORK_LOCK_SCHEMA_INVALID`, `FRAMEWORK_LOCK_INVALID`, `FRAMEWORK_LOCK_IDENTITY_INVALID` | The file lacks fields, or the versions in it do not agree with each other. **What to do:** Replace the file with the shipped one. |
| `FRAMEWORK_MOVING_REFERENCE_FORBIDDEN`, `FRAMEWORK_ASSET_MOVING_REFERENCE_FORBIDDEN` | The version is given by a moving reference (`main`, `master`, `latest`) whose content changes over time. **What to do:** Give an exact version like `v1.2.3`, or replace the file with the shipped one. |
| `FRAMEWORK_RUNTIME_RELEASE_REFERENCE_INVALID`, `FRAMEWORK_ASSET_COMMIT_REQUIRED` | The version is not written as `v1.2.3`, or a file address has no exact commit. **What to do:** Replace the file with the shipped one. |
| `FRAMEWORK_MANIFEST_NOT_LOCKED`, `FRAMEWORK_MANIFEST_UPSTREAM_REVISION_MISMATCH`, `FRAMEWORK_RUNTIME_PROJECTION_MISMATCH` | The lock file names a different Framework version than the installed Docara ships, usually after a Docara update. **What to do:** Replace the file with the shipped one. |
| `FRAMEWORK_LOCK_CHANGED_DURING_BUILD` | The lock file changed while the build was running. **What to do:** Wait until the edit is finished and build again. |
| `FRAMEWORK_RUNTIME_MISSING` | The project has no pages. **What to do:** Add a page to a language folder, for example `content/en/index.md`. |
| `FRAMEWORK_ASSET_PLAN_NOT_STABLE` | After the page was output, the set of Framework files it needs changed. **What to do:** Rebuild the site; if the error repeats, report it. |

## Component call

| Code | Cause and what to do |
| --- | --- |
| `FRAMEWORK_PRESET_UNKNOWN` | The SIMAI Framework component has no preset with this name. **What to do:** Take the name from `docara inspect smart <component> --json` or remove `preset`. |
| `FRAMEWORK_PRESET_INVALID` | `preset` is not written as a string. **What to do:** Write `"preset": "name"`. |

## Loading warnings

Usually Docara knows in advance which Framework styles and scripts a page
needs, and connects only those. These warnings report that part of the code
will load on demand in the browser. The build does not stop, and the site
works.

| Code | What it means |
| --- | --- |
| `FRAMEWORK_COMPONENT_DYNAMIC_FALLBACK`, `FRAMEWORK_SMART_DYNAMIC_FALLBACK`, `FRAMEWORK_RELATION_DYNAMIC_FALLBACK` | A component or its dependency will load in the browser on demand. **What to do:** Nothing, if the page works. |
| `FRAMEWORK_SHELL_PRELOAD_METADATA_MISSING` | The pinned version has no list of files to preload. **What to do:** Nothing; the warning goes away after Docara and the lock file are updated. |
