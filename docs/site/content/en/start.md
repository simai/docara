# Get started

This section takes you from meeting Docara to a first built page open in the
browser.

:::steps
1. [What Docara is](/en/start/what-is-docara/) — when to choose it, what the
   build needs and how it differs from VitePress, Docusaurus and MkDocs.
2. [Quick start](/en/start/quick-start/) — four steps from an empty folder to
   a site open over HTTP.
3. [Tutorial: a first landing page](/en/start/first-landing/) — a page with a
   first screen, benefits and a call to action in 15 minutes.
4. [Tutorial: a first project component](/en/start/first-component/) — your
   own component from a scaffold, styled with SIMAI Framework classes.
5. [Starters and environment](/en/start/templates/) — which starter to pick in
   `init`, which files it creates and how to check the installation.
6. [Project files](/en/start/project-files/) — what the site folder holds,
   which files you edit and which Docara creates.
7. [How components work](/en/start/component-model/) — when plain Markdown is
   enough and when you need a component.

:::

Then go on to [Writing pages](/en/authoring/), and when the site is ready
to publish, to [Building and publishing](/en/build/).
