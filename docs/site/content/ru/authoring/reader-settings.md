# Настройки чтения

Кнопка настройки в шапке открывает боковую панель справа. Панель строит
продуктовый Smart-компонент `docara.preferences`, а поведение модального окна,
затемнение, фокус, закрытие по `Escape` и блокировку прокрутки предоставляет
`sf-modal` SIMAI Framework.

Сейчас в обязательный набор входит одна настройка — тема:

- **Как в системе** — тема следует режиму устройства;
- **Светлая** — всегда используется светлая тема;
- **Тёмная** — всегда используется тёмная тема.

Изменение применяется сразу. Отдельная кнопка сохранения не нужна.

## Значение по умолчанию

Автор задаёт тему сайта через наследуемую ветку `settings`:

```json
{
  "settings": {
    "theme": "system"
  }
}
```

Это значение можно переопределять в `section.json` и `<page>.page.json`.
Локальный выбор читателя имеет приоритет. Команда «Вернуть настройку сайта»
удаляет только пользовательское переопределение и снова применяет значение
текущей страницы.

## Какие поля показывать

Состав панели задаётся только на уровне сайта в `docara.json`:

```json
{
  "reader_preferences": {
    "enabled": true,
    "view": "side-panel",
    "groups": [
      {
        "id": "appearance",
        "fields": ["appearance.theme"]
      }
    ]
  }
}
```

`enabled: false` полностью убирает кнопку, Smart-компонент и его ассеты.
Неизвестное поле, повтор, неверная группа или неподдерживаемое представление
останавливают сборку. В `section.json` и page sidecar эта ветка запрещена:
один сайт не должен менять состав пользовательских настроек от страницы к
странице.

Новые настройки добавляются через реестр определений. Определение сообщает
идентификатор, группу, допустимые значения, вид элемента управления, безопасный
эффект, момент применения и ключи локализованного текста. `docara.json` только
выбирает, какие зарегистрированные поля показать, и не содержит исполняемого
кода.

## Хранение и приватность

Docara сохраняет один версионированный JSON-документ в `localStorage`:

```json
{
  "schema": 1,
  "values": {
    "appearance.theme": "dark"
  }
}
```

Ключ изолирован по `base_url` сайта и имеет вид
`docara.preferences.<site-hash>.v1`. Хранятся только отличия от авторских
значений. Аккаунт, сервер, аналитика, cookie и старые ключи темы не
используются.

Настройки с фазой `prepaint` восстанавливаются до первого отображения страницы.
Если постоянное хранилище недоступно, выбор работает до перезагрузки, а панель
честно сообщает об этом. Изменение в другой вкладке синхронизируется через
событие браузера `storage`.

## Почему пока только тема

Масштаб текста уже надёжно меняется средствами браузера и операционной системы.
Ширину общей сетки задаёт автор через `layout.container.max` и штатные
`max-container-N` SIMAI Framework. Поэтому Docara не создаёт параллельные
значения в пикселях или rem без подтверждённой пользовательской задачи.

Реестр и универсальный renderer уже позволяют позже добавить новые поля без
переписывания панели. Каждый новый эффект при этом должен быть явно внесён в
безопасный список runtime, протестирован и документирован.
