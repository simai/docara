# Компоненты

Здесь собраны страницы конкретных компонентов и поддерживаемых конструкций
Docara. Если вы сначала хотите понять разницу между Markdown, inline-блоками,
контейнерами, Framework и project-owned расширениями, откройте
[модель компонентов](/ru/start/component-model/).

## Текст и Markdown

Эти конструкции — обычный Markdown без компонентов. Все они описаны на одной
странице, [«Markdown»](/ru/authoring/markdown/).

| Конструкция | Для чего |
| --- | --- |
| [Заголовки и текст](/ru/authoring/markdown/#заголовки-и-текст) | Заголовки, абзацы и выделение текста обычным Markdown |
| [Ссылки и изображения](/ru/authoring/markdown/#ссылки-и-изображения) | Ссылки на страницы и сайты, картинки с подписью для доступности |
| [Списки и цитаты](/ru/authoring/markdown/#списки-и-цитаты) | Маркированные и нумерованные списки и цитаты |
| [Чеклисты и определения](/ru/authoring/markdown/#чеклисты-и-определения) | Задачи с галочками и термины с определениями |
| [Сноски и источники](/ru/authoring/markdown/#сноски-и-источники) | Сноски с номером и список источников внизу страницы |
| [Таблица](/ru/authoring/markdown/#таблицы) | Таблица Markdown; на узком экране прокручивается внутри себя |
