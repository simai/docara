# Компоненты

Компоненты Docara помогают оформлять документацию, примеры и сложные интерфейсные фрагменты без ручной HTML-разметки. Начните с одного из шести способов расширения: от обычного Markdown до project-owned LEGO-компонента.

## Шесть точек входа

### [Обычный Markdown](/ru/components/native-markdown/)

Заголовки, текст, ссылки, изображения, списки, цитаты, код, таблицы и сноски.

### [Inline Docara](/ru/components/inline-docara/)

Небольшой компонент внутри строки без ручного HTML.

### [Block Docara](/ru/components/block-docara/)

Самостоятельные документные блоки с типизированными параметрами.

### [Контейнеры и композиция](/ru/components/containers/)

Разрешённые вложения, slots, порядок, количество и глубина.
Для общей полосы используйте [Surface](/ru/components/surface/); Hero,
Showcase и Promo уже используют ту же presentation geometry без авторской
обёртки.

### [SIMAI Framework](/ru/components/framework/)

Только exact-pinned и принятые `ui.*` Smart artifacts.

### [Собственные компоненты](/ru/components/project/)

Project-owned content и shell contributions без изменения engine.
