# Компоненты

Здесь собраны страницы конкретных компонентов и поддерживаемых конструкций
Docara. Если вы сначала хотите понять разницу между Markdown, inline-блоками,
контейнерами, Framework и project-owned расширениями, откройте
[модель компонентов](/ru/start/component-model/).

## Текст и Markdown

| Компонент | Для чего |
| --- | --- |
| [Заголовки и текст](/ru/components/headings-and-text/) | Заголовки, абзацы и выделение текста обычным Markdown |
| [Ссылки и изображения](/ru/components/links-and-images/) | Ссылки на страницы и сайты, картинки с подписью для доступности |
| [Списки и цитаты](/ru/components/lists-and-quotes/) | Маркированные и нумерованные списки, задачи с галочками, цитаты |
| [Сноски и источники](/ru/components/footnotes-and-sources/) | Сноски с номером и список источников внизу страницы |
