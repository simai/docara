# Уведомление

Уведомление сообщает важную информацию, результат, предупреждение или ошибку
в едином стиле SIMAI Framework.

## Общий пример

Используйте информационный тип для полезного пояснения, которое не требует
немедленного действия.

:::example {label="Общий пример"}
```markdown
:::alert {type=info variant=default}
#### Полезная информация

Продолжайте работу в обычном порядке.
:::
```
:::

## Смысл

Параметр `type` выбирает семантический тип уведомления.

| Значение | Результат |
| --- | --- |
| `clear` | Нейтральное сообщение |
| `info` | Информация · **По умолчанию** |
| `success` | Успешное завершение |
| `warning` | Предупреждение |
| `danger` | Ошибка, требующая внимания |

:::alert {type=clear}
#### К сведению

Это сообщение не требует действия.
:::

:::alert {type=success}
#### Готово

Сборка успешно прошла проверку.
:::

:::alert {type=warning variant=outlined}
#### Обратите внимание

Проверьте параметры перед публикацией.
:::

:::alert {type=danger variant=flat}
#### Требуется исправление

Конфигурация не прошла проверку.
:::

## Оформление

Параметр `variant` меняет визуальную плотность, но не смысл уведомления.

| Значение | Результат |
| --- | --- |
| `default` | Обычное оформление · **По умолчанию** |
| `flat` | Плоское оформление без лишнего акцента |
| `outlined` | Контурное оформление |

## Вызов

В заголовке кратко назовите ситуацию, а ниже объясните результат или следующее
действие. Цвет не должен быть единственным способом передать смысл.

```markdown
:::alert {type=warning variant=outlined}
#### Обратите внимание

Проверьте параметры перед публикацией.
:::
```

Допустимые значения `type`: `clear`, `info`, `success`, `warning`, `danger`.
Допустимые значения `variant`: `default`, `flat`, `outlined`.
