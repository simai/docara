# Обратные ссылки

Обратные ссылки показывают страницы этой же сборки, которые ведут на текущий
материал. Список строится сам из внутренних ссылок, поддерживать его вручную
не нужно. Ставьте блок в конце статьи, после основного текста.

## Пример

:::example {label="Обратные ссылки"}
```markdown
:::backlinks
:::
```
:::

## Разметка

```markdown
:::backlinks {limit=10}
:::
```

- Блок пустой: содержимое собирает сборка.
- Учитываются только внутренние ссылки страниц той же сборки. Внешние ссылки
  и ссылки из меню не считаются.

## Варианты

### Длина списка

`limit` ограничивает число ссылок, от `1` до `50`. Если входящих ссылок
больше, остаются первые в постоянном порядке, поэтому список не меняется от
сборки к сборке.

:::example {label="Не больше двух ссылок"}
```markdown
:::backlinks {limit=2}
:::
```
:::

## Состояния

### Ссылок нет

Если на страницу ещё никто не ссылается, блок показывает короткое сообщение
об этом, а не пустое место.

## Доступность

- Блок — раздел со своим заголовком «Ссылаются на эту страницу» и обычным
  списком ссылок: программы экранного доступа переходят к нему по заголовку.
- Название каждой ссылки — заголовок страницы, на которую она ведёт.
- Блок дополняет навигацию статьи, но не заменяет её: важные переходы
  ставьте в текст или в «См. также».

## Параметры

<!-- docara:component-parameters:start -->

| Параметр | Значения | По умолчанию | Что задаёт |
| --- | --- | --- | --- |
| `limit` | целое число | `5` | Сколько входящих ссылок показать. |
