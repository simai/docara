# Обратные ссылки

Обратные ссылки показывают страницы текущей сборки, которые ведут на этот
материал. Список строится автоматически из внутренних ссылок — поддерживать его
вручную не нужно.

## Общий пример

:::example {label="Общий пример"}
```markdown
:::backlinks {limit=5}
:::
```
:::

Если другие страницы уже ссылаются сюда, ниже появится их список. В противном
случае Docara покажет понятное сообщение об отсутствии ссылок.

:::backlinks {limit=5}
:::

## Количество ссылок

Параметр `limit` ограничивает длину списка.

| Значение | Результат |
| --- | --- |
| Не указан | До 5 ссылок · **По умолчанию** |
| `1`–`50` | Не больше указанного числа ссылок |

Если входящих ссылок больше лимита, Docara оставляет первые элементы в
стабильном порядке. Учитываются только внутренние страницы той же сборки.

## Вызов

```markdown
:::backlinks {limit=10}
:::
```

Размещайте блок после основного материала. Он является производным
представлением ссылочного графа и не заменяет обычную навигацию статьи.
