# Баннер

Баннер показывает короткое объявление, которое относится ко всей странице:
к версии документации, сроку действия или важному изменению. Для заметки рядом
с конкретным шагом выбирайте [уведомление](../alert/).

## Пример

:::example {label="Баннер"}
```markdown
:::banner {type=info}
Эта версия документации относится к текущей стабильной сборке.
:::
```
:::

## Разметка

```markdown
:::banner {type=warning}
Одно-два предложения: что изменилось и что делать.
:::
```

- Внутри — обычный Markdown, без заголовка. Баннер без текста останавливает
  сборку.
- Ставьте баннер в начало страницы, до основного текста.

Баннер построен на уведомлении SIMAI Framework (`sf-alert`) в плоском виде.

## Варианты

### Тип

`type` задаёт смысл объявления: от него зависят цвет и значок.

:::example {label="Типы баннера"}
```markdown
:::banner {type=info}
Эта версия документации относится к текущей стабильной сборке.
:::

:::banner {type=success}
Документация обновлена до текущей стабильной версии.
:::

:::banner {type=warning}
Перед обновлением сохраните текущую сборку.
:::

:::banner {type=danger}
Эта версия больше не получает исправления безопасности.
:::
```
:::

## Доступность

- Баннер — область `status`: программы экранного доступа объявляют его как
  отдельное сообщение.
- Смысл передают значок и текст, а не только цвет. Называйте последствие или
  следующее действие словами.
- Один баннер на страницу: несколько объявлений подряд читатель пропускает.

## Параметры

<!-- docara:component-parameters:start -->

| Параметр | Значения | По умолчанию | Что задаёт |
| --- | --- | --- | --- |
| `type` | `info`, `success`, `warning`, `danger` | `info` | Смысл сообщения: сведения, успех, предупреждение или опасность. |
