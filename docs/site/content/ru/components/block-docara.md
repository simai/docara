# Блочные компоненты Docara

Блок занимает самостоятельное место в Document IR. Один directive-name разрешается typed definition repository и рендерится общей registry, а Smart leaves проходят единый Gateway.

## Принятые block entries

:::atlas_index {kind=smart authoring=block}
:::

## Исходник и результат

:::example {label=Alert}
```markdown
:::alert {type=info variant=default}
#### Безопасное применение

Сначала выполните dry-run, затем применяйте hash-bound plan.
:::
```
:::

## Props и доступность

Используйте только параметры со страницы конкретного компонента. Заголовок и содержимое должны объяснять действие без опоры на цвет; интерактивные элементы обязаны иметь видимый focus.

## Ошибка

Неизвестный directive, лишний prop, пустой обязательный body или незакрытый fence отклоняются до публикации. Engine не ищет PHP/template path из Markdown.
