# Содержательные блоки

Блоки, которые стоят в тексте страницы: уведомления, шаги, вкладки, примеры и другие.

| Компонент | Для чего |
| --- | --- |
| [Уведомление](/ru/components/blocks/alert/) | Заметка, совет или предупреждение рядом с текстом |
| [Баннер](/ru/components/blocks/banner/) | Короткое объявление, которое относится ко всей странице |
| [Раскрывающийся блок](/ru/components/blocks/details/) | Дополнительное пояснение, которое читатель открывает сам |
| [Интерактивный пример](/ru/components/blocks/example/) | Живой результат рядом с исходным кодом |
| [Шаги](/ru/components/blocks/steps/) | Пронумерованная инструкция из нескольких шагов |
| [Вкладки](/ru/components/blocks/tabs/) | Несколько равноценных вариантов, например для разных систем |
| [Дерево файлов](/ru/components/blocks/tree/) | Структура папок и файлов проекта |
| [Обратные ссылки](/ru/components/blocks/backlinks/) | Список страниц сайта, которые ссылаются на текущую |

## Как выбрать

Если читатель не должен пропустить мысль, возьмите уведомление; если объявление
касается всей страницы — баннер. Порядок действий оформите шагами, а равноценные
варианты, например команды для разных систем, — вкладками. Подробности, которые
нужны не всем, спрячьте в раскрывающийся блок. Живой результат рядом с исходным
кодом показывает интерактивный пример.
