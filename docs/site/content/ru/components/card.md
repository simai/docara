# Карточка

Карточка объединяет заголовок и связанный с ним текст на отдельной поверхности.
Она подходит для кратких пояснений, вариантов и небольших групп ссылок.

## Общий пример

:::example {label="Общий пример"}
```markdown
:::card
### Переносимый проект

Markdown и JSON можно хранить рядом с кодом и проверять через Git.
:::
```
:::

## Оформление

Параметр `variant` выбирает самостоятельную поверхность или нейтральный
контейнер для использования внутри другой композиции.

| Значение | Результат |
| --- | --- |
| `default` | Поверхность, рамка и внутренние отступы · **По умолчанию** |
| `plain` | Содержимое без собственной рамки и отступов |

:::example {label="Варианты"}
```markdown
:::card {variant=default}
### Карточка с оформлением

Поверхность, рамка и внутренние отступы применяются автоматически.
:::

:::card {variant=plain}
### Карточка без оформления

Используйте этот вариант внутри сетки, когда отдельная поверхность не нужна.
:::
```
:::

## Вызов

```markdown
:::card {variant=default}
### Понятный заголовок

Короткое связанное содержимое.
:::
```

Не используйте карточку только ради рамки вокруг длинной статьи. Вложенные
типизированные директивы внутри карточки не поддерживаются.
