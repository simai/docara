# Код и данные

Код, схемы, формулы и справка по компонентам, которые хранятся рядом с текстом.

| --- | --- |
| [Код](/ru/components/code-and-data/code/) | Блок кода с подсветкой, копированием и переносом строк |
| [Код из файла](/ru/components/code-and-data/code-from-file/) | Фрагмент файла проекта, который обновляется вместе с файлом |

## Как выбрать

Короткий фрагмент кода пишите прямо в тексте блоком кода. Если фрагмент взят из
файла проекта, подключите его как код из файла: он обновится вместе с файлом.
Связи и процессы показывайте диаграммой, формулы — в записи TeX. Справочник
компонента собирает атрибуты, события и методы из манифеста, поэтому таблицу
параметров не нужно вести вручную.
