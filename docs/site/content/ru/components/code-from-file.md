# Код из файла

Блок вставляет проверенный фрагмент локального файла без копирования кода в
Markdown. Изменение исходника автоматически отражается в документации.

## Общий пример

:::example {label="Общий пример"}
```markdown
:::code {src="../../../snippets/install.php" lang=php lines="1-8" title="install.php"}
:::
```
:::

## Параметры

| Параметр | Назначение |
| --- | --- |
| `src` | Обязательный путь к файлу относительно папки страницы |
| `lang` | Язык подсветки: строчные латинские буквы, цифры, `_`, `+` или `-`, до 32 знаков. По умолчанию — расширение файла, а без расширения `text` |
| `lines` | Одна строка `4` или диапазон `4-12`; нумерация с единицы |
| `region` | Название области в файле, отмеченной `#region` и `#endregion` |
| `start_after` | Показать строки после первой строки, где есть этот текст |
| `end_before` | Закончить перед строкой, где есть этот текст |
| `dedent` | `true` убирает общий отступ показанных строк |
| `title` | Подпись над блоком. По умолчанию — имя файла |
| `highlight`, `numbers`, `focus`, `layout` | Те же параметры, что у [обычного блока кода](/ru/components/code/) |

Фрагмент выбирается одним способом: `lines`, `region` или пара
`start_after` и `end_before`. Если указать два способа сразу, сборка
остановится с кодом `MARKDOWN_CODE_OPTIONS_CONFLICT`.

## Область файла

Область отмечают в самом файле комментарием на языке файла:
`// #region build` и `// #endregion build`. Так же подходят `# region build`
и `<!-- #region build -->`. Строки с метками на странице не показываются.
Если области с таким названием нет, сборка остановится с кодом
`MARKDOWN_CODE_REGION_UNKNOWN`.

:::example {label="Область build с номерами строк файла"}
```markdown
:::code {src="../../../snippets/site-builder.php" region=build dedent=true numbers highlight=3}
:::
```
:::

С `numbers` счёт идёт по строкам файла: на странице видно, где фрагмент
находится в исходнике. `highlight` считает строки от начала фрагмента.

## Между строками-метками

Если в файле нет областей, фрагмент можно выбрать по тексту соседних строк:

```markdown
:::code {src="../../../snippets/site-builder.php" start_after="#region read" end_before="#endregion read"}
:::
```

Строки с текстом `start_after` и `end_before` в фрагмент не входят.

## Ограничения

Файл читается во время сборки, поэтому код на странице всегда совпадает с
исходником в момент публикации. Сборка проверяет файл заранее и
останавливается, если:

- путь абсолютный или ведёт за пределы корня проекта;
- файла нет, это папка или символическая ссылка;
- файл больше 1 МиБ или записан не в кодировке UTF-8;
- диапазон `lines` записан неверно, конец раньше начала или начало дальше
  последней строки файла;
- области `region` или текста `start_after` и `end_before` нет в файле.

Если конец диапазона больше числа строк, блок покажет строки до конца файла.
Коды ошибок и способы исправления — в разделе
[«Код из файла»](/ru/reference/errors/content/#код-из-файла) справочника ошибок.
