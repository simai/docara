# Код из файла

Блок вставляет проверенный фрагмент локального файла без копирования кода в
Markdown. Изменение исходника автоматически отражается в документации.

## Общий пример

:::example {label="Общий пример"}
```markdown
:::code {src="../../../snippets/install.php" lang=php lines="1-8" title="install.php"}
:::
```
:::

## Параметры

| Параметр | Назначение |
| --- | --- |
| `src` | Обязательный относительный путь внутри проекта |
| `lang` | Язык подсветки; по умолчанию расширение файла |
| `lines` | Одна строка `4` или диапазон `4-12` |
| `title` | Понятная подпись блока |

## Рабочий результат

:::code {src="../../../snippets/install.php" lang=php lines="1-8" title="install.php"}
:::

## Вызов

```markdown
:::code {src="../../../snippets/install.php" lang=php lines="1-8" title="install.php"}
:::
```

Путь не может выходить за корень проекта. Символические ссылки, файлы больше
1 МиБ и диапазоны вне файла отклоняются до публикации.
