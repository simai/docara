# Код из файла

Блок вставляет фрагмент файла проекта, не копируя код в Markdown. Файл
читается при сборке, поэтому код на странице всегда совпадает с исходником в
момент публикации.

## Пример

:::example {label="Код из файла"}
```markdown
:::code {src="../../../snippets/install.php" lines="1-8"}
:::
```
:::

## Разметка

```markdown
:::code {src="../../../snippets/install.php" lines="1-8"}
:::
```

- Блок пустой: код берётся из файла `src`. Путь — относительно папки
  страницы и не выходит за пределы проекта.
- Язык и подпись берутся из имени файла; их можно задать `lang` и `title`.
- Фрагмент выбирается одним способом: `lines`, `region` или пара
  `start_after` и `end_before`. Два способа сразу останавливают сборку с
  кодом `MARKDOWN_CODE_OPTIONS_CONFLICT`.
- `highlight`, `numbers`, `focus` и `layout` работают как у
  [обычного блока кода](../code/).

## Варианты

### Строки файла

`lines` — одна строка `4` или диапазон `4-12`, с единицы. Если конец
диапазона больше числа строк, показываются строки до конца файла.

### Область файла

Область отмечают в самом файле комментарием на языке файла:
`// #region build` и `// #endregion build`. Так же подходят `# region build`
и `<!-- #region build -->`. Строки с метками на странице не показываются.

:::example {label="Область build с номерами строк файла"}
```markdown
:::code {src="../../../snippets/site-builder.php" region=build dedent=true numbers highlight=3}
:::
```
:::

С `numbers` счёт идёт по строкам файла: видно, где фрагмент находится в
исходнике. `highlight` считает строки от начала фрагмента. `dedent=true`
убирает общий отступ показанных строк.

### Между строками-метками

Если в файле нет областей, фрагмент выбирают по тексту соседних строк. Строки
с текстом `start_after` и `end_before` в фрагмент не входят.

:::example {label="Между строками-метками"}
```markdown
:::code {src="../../../snippets/site-builder.php" start_after="#region read" end_before="#endregion read"}
:::
```
:::

## Состояния

### Проверка при сборке

Сборка проверяет файл заранее и останавливается, если:

- путь абсолютный или ведёт за пределы корня проекта;
- файла нет, это папка или символическая ссылка;
- файл больше 1 МиБ или записан не в кодировке UTF-8;
- диапазон `lines` записан неверно, конец раньше начала или начало дальше
  последней строки файла;
- области `region` или текста `start_after` и `end_before` нет в файле.

Коды ошибок и способы исправления — в разделе
[«Код из файла»](/ru/reference/errors/content/#код-из-файла) справочника
ошибок.

## Доступность

- Блок выглядит и работает как обычный блок кода: те же кнопки копирования и
  переноса, те же отметки изменений.
- Подпись над блоком по умолчанию — имя файла. Если фрагмент — часть файла,
  дайте подпись, которая это объясняет: `title="install.php, установка"`.

## Параметры

<!-- docara:component-parameters:start -->

| Параметр | Значения | По умолчанию | Что задаёт |
| --- | --- | --- | --- |
| `src` (обязательный) | строка | — | Путь к файлу проекта, из которого берётся код. |
| `lang` | строка | `text` | Язык для подсветки синтаксиса. |
| `lines` | строка | — | Диапазон строк файла, например `10-24`. |
| `title` | строка | — | Подпись над кодом. Без неё показывается имя файла. |
| `highlight` | строка | — | Строки, которые нужно выделить: номера и диапазоны через запятую. |
| `numbers` | строка | `false` | Показывать номера строк: `true` или номер первой строки. |
| `focus` | строка | — | Строки в фокусе: остальные приглушаются. |
| `layout` | `default`, `terminal` | `default` | `terminal` оформляет блок как окно терминала. |
| `region` | строка | — | Имя области, отмеченной в файле комментариями `#region` и `#endregion`. |
| `start_after` | строка | — | Строка-метка: код берётся со следующей за ней строки. |
| `end_before` | строка | — | Строка-метка: код берётся до неё. |
| `dedent` | `true`, `false` | `false` | Убрать общий отступ у всех строк фрагмента. |

<!-- docara:component-parameters:end -->
