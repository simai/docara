# Код

Любой фрагмент между тремя обратными кавычками Docara оформляет как блок кода.
Это может быть HTML, PHP, JSON, команда терминала, конфигурация или обычный
текст. Блок ничего не выполняет: он сохраняет пробелы и переносы, подсвечивает
синтаксис и позволяет скопировать содержимое.

## Блок с указанным языком

Язык задаётся сразу после открывающих обратных кавычек. Он появляется в
заголовке и выбирает правила подсветки.

```html
<article class="p-2 radius-2 bg-surface-container">
    <h2 class="sf-h-3 m-0">Карточка интерфейса</h2>
    <p class="m-0 m-top-1">Одна разметка, понятные модификаторы.</p>
</article>
```

## Блок без указанного языка

Если язык не передан, в заголовке используется нейтральное название `Code`.

```
composer install
```

## Язык и оформление

После открывающих обратных кавычек укажите язык: `php`, `json`, `bash`,
`javascript` или другой поддерживаемый идентификатор. Он появляется в
заголовке блока и помогает подсветке синтаксиса.

| Запись | Результат |
| --- | --- |
| `` ```php `` | PHP-код |
| `` ```json `` | JSON |
| `` ```text `` | Текст без языковой семантики |

Длинная строка прокручивается внутри блока и не растягивает всю страницу.
Если скрипт должен быть запущен, отдельно объясните окружение и ожидаемый
результат: сам блок ничего не выполняет.

## Как записать в Markdown

~~~markdown
```php
echo 'Готово';
```
~~~

Не помещайте в пример пароли, токены и другие секреты. Для команды с выводом
используйте понятное разделение между тем, что вводит человек, и результатом.
