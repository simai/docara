# Код

Любой фрагмент между тремя обратными кавычками Docara оформляет как блок кода.
Это может быть HTML, PHP, JSON, команда терминала, конфигурация или обычный
текст. Блок ничего не выполняет: он сохраняет пробелы и переносы, подсвечивает
синтаксис, позволяет скопировать содержимое и при необходимости мягко перенести
длинные строки в пределах доступной ширины.

## Блок с указанным языком

Язык задаётся сразу после открывающих обратных кавычек. Он появляется в
заголовке и выбирает правила подсветки.

```html
<article class="p-2 radius-2 bg-surface-container">
    <h2 class="sf-h-3 m-0">Карточка интерфейса</h2>
    <p class="m-0 m-top-1">Одна разметка, понятные модификаторы.</p>
</article>
```

## Блок без указанного языка

Если язык не передан, в заголовке используется нейтральное название `Code`.

```
composer install
```

## Параметры блока

Параметры пишутся в фигурных скобках после языка, так же как у других блоков
Docara: `` ```php {title="app.php" highlight="2-3" numbers} ``. Порядок не
важен. Параметр без значения, например `numbers`, означает «включить».

| Параметр | Что делает |
| --- | --- |
| `title` | Имя файла или подпись в заголовке вместо названия языка |
| `highlight` | Выделяет строки: `highlight="1,4-6"` |
| `numbers` | Нумерует строки; `numbers=10` начинает счёт с десяти |
| `focus` | Оставляет в фокусе указанные строки, остальные приглушает |
| `layout` | `terminal` оформляет блок как окно терминала |

Строки считаются от первой строки блока, начиная с единицы. Если номер строки
больше, чем строк в блоке, или диапазон записан наоборот, сборка
останавливается с кодом `MARKDOWN_CODE_RANGE_INVALID`.

Те же параметры понимает [код из файла](/ru/components/code-from-file/).

## Имя файла

:::example {label="Имя файла в заголовке"}
````markdown
```php {title="config/app.php"}
return [
    'name' => 'Docara',
];
```
````
:::

## Выделение и номера строк

:::example {label="Выделенные строки с номерами"}
````markdown
```php {highlight="2-3" numbers}
$site = new Site('docs');
$site->theme('light');
$site->build();
echo 'Готово';
```
````
:::

Нумерацию можно начать с любого числа, например с номера строки в файле:
`numbers=42`.

## Изменения в коде

Чтобы показать, что добавлено и что удалено, допишите в конце строки
комментарий-метку. Метка пишется так, как в языке пишутся комментарии:
`// [!code ++]`, `# [!code --]` или `<!-- [!code ++] -->`. Docara убирает
метку из показанного кода.

| Метка | Что означает |
| --- | --- |
| `[!code ++]` | Строка добавлена |
| `[!code --]` | Строка удалена |
| `[!code focus]` | Строка в фокусе |
| `[!code highlight]` | Строка выделена |

:::example {label="Добавленная и удалённая строка"}
````markdown
```js
const site = createSite();
site.build(); // [!code --]
await site.build(); // [!code ++]
```
````
:::

Добавленные строки отмечены знаком «+» и зелёным фоном, удалённые — знаком «−»
и красным фоном, поэтому разница видна не только по цвету. Программа
экранного доступа перед такой строкой произносит «добавлено» или «удалено».
Слова можно заменить в `lang.json` ключами `code.added` и `code.removed`.

Чтобы показать саму метку как текст, напишите два восклицательных знака:
`[!!code ++]` выводится как `[!code ++]`. В блоках `markdown` метки не
обрабатываются, чтобы пример разметки показывался как есть.

## Фокус

:::example {label="Фокус на одной строке"}
````markdown
```js {focus=2}
const site = createSite();
site.theme('dark');
site.build();
```
````
:::

Остальные строки становятся бледнее. Наведите указатель на блок или перейдите
в него клавиатурой — все строки снова видны полностью.

## Терминал

`layout=terminal` оформляет блок как окно терминала. Строка, которая
начинается с `$ `, — это команда: знак `$` показан отдельно и не копируется.
Остальные строки — вывод команды.

:::example {label="Команды и вывод в терминале"}
````markdown
```bash {layout=terminal}
$ composer require simai/docara
Using version ^3.9 for simai/docara
$ php vendor/bin/docara build
Built 12 page(s) into build_local.
```
````
:::

## Копирование

Кнопка «Скопировать» копирует только код, который нужно перенести к себе:

- без номеров строк, знаков «+» и «−» и меток `[!code …]`;
- без удалённых строк — копируется код после изменения;
- в терминале — только команды, без знака `$` и без вывода.

## Перенос длинных строк

По умолчанию длинная строка прокручивается внутри блока и не растягивает всю
страницу. Кнопка «Переносить длинные строки» включает только визуальный
CSS-перенос. Исходный текст, отступы и результат копирования не меняются.
Когда перенос включён, значок меняется на команду возврата к исходным строкам.
Видимая рамка фокуса появляется при переходе клавиатурой, но не после щелчка
мышью. Выбор общий для обычных блоков и вкладок исходника в Example,
сохраняется в браузере и синхронно применяется ко всем таким блокам на странице.

Возможность переноса включена встроенным параметром `code.wrap`. Её можно
отключить для сайта, раздела или страницы:

```json
{
  "code": {
    "wrap": false
  }
}
```

Если скрипт должен быть запущен, отдельно объясните окружение и ожидаемый
результат: сам блок ничего не выполняет.

## Как записать в Markdown

~~~markdown
```php {title="install.php" highlight=2 numbers}
<?php
echo 'Готово';
```
~~~

Запись совместима с привычными инструментами. Как в MkDocs Material, параметры
пишутся словами после языка, только в фигурных скобках, как у остальных блоков
Docara. Как в VitePress, метки изменений пишутся комментарием `[!code ++]`, а
короткая запись `` ```js{1,4-6} `` выделяет строки.

Не помещайте в пример пароли, токены и другие секреты. Для команды с выводом
используйте `layout=terminal`: так видно, что вводит человек, а что выводит
программа.
