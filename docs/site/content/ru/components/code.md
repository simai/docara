# Код

Блок кода показывает готовый фрагмент без выполнения и сохраняет пробелы,
переносы и название языка. Читатель может скопировать пример одной кнопкой.

## Общий пример

:::example {label="Общий пример"}
~~~markdown
```php
$site = 'Docara';
echo $site;
```
~~~
:::

## Язык и оформление

После открывающих обратных кавычек укажите язык: `php`, `json`, `bash`,
`javascript` или другой поддерживаемый идентификатор. Он появляется в
заголовке блока и помогает подсветке синтаксиса.

| Запись | Результат |
| --- | --- |
| `` ```php `` | PHP-код |
| `` ```json `` | JSON |
| `` ```text `` | Текст без языковой семантики |

Длинная строка прокручивается внутри блока и не растягивает всю страницу.
Если скрипт должен быть запущен, отдельно объясните окружение и ожидаемый
результат: сам блок ничего не выполняет.

## Вызов

~~~markdown
```php
echo 'Готово';
```
~~~

Не помещайте в пример пароли, токены и другие секреты. Для команды с выводом
используйте понятное разделение между тем, что вводит человек, и результатом.
