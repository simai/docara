# Раскрывающийся блок

Раскрывающийся блок прячет дополнительное пояснение, пока читатель не решит
его открыть. Основная инструкция при этом должна оставаться видимой на странице.

## Общий пример

:::example {label="Общий пример"}
```markdown
:::details
## Что произойдёт после сборки?

Docara создаст статический сайт, который можно открыть без серверного runtime.
:::
```
:::

## Оформление

Параметр `view` выбирает вид блока.

| Значение | Результат |
| --- | --- |
| `surface` | Самостоятельная карточка · **По умолчанию** |
| `lines` | Компактный раздел между линиями |

:::details {view=lines}
## Линейный вариант

Подходит для нескольких последовательных вопросов внутри одной статьи.
:::

## Начальное состояние

Обычно блок закрыт. Добавьте `open=true`, только когда пояснение важно увидеть
сразу, но оно всё ещё остаётся дополнительным к основному тексту.

:::details {view=surface open=true}
## Открыто изначально

Содержимое видно сразу, а читатель при желании может его свернуть.
:::

## Вызов

```markdown
:::details {view=lines open=true}
## Короткий и понятный вопрос

Полезное дополнительное пояснение.
:::
```

Заголовок внутри блока обязателен. Используйте уровень `##`, `###` или `####`.
Не прячьте обязательные действия, ошибки и предупреждения. Для автоматически
собираемого списка входящих ссылок используйте [обратные ссылки](../backlinks/).
