# Диаграмма

Диаграмма хранит схему Mermaid рядом с текстом статьи, а браузер рисует её
как SVG. Это удобно для проверяемых потоков и связей, которые меняются
вместе с документацией.

## Общий пример

:::example {label="Общий пример"}
```markdown
:::diagram {engine=mermaid title="Цепочка сборки"}
flowchart LR
  Markdown --> Parser
  Parser --> HTML
:::
```
:::

## Параметры

`engine` сейчас принимает только `mermaid`. Параметр `title` задаёт доступное
название схемы; формулируйте его так, чтобы смысл был понятен без исходного кода.

## Вызов

```markdown
:::diagram {engine=mermaid title="Публикация документации"}
flowchart LR
  Author --> Build
  Build --> Verify
  Verify --> Publish
:::
```

Используйте поддерживаемый синтаксис Mermaid и короткие подписи узлов.

## Как показывается схема

Сборка кладёт исходник схемы в HTML как текст, а на страницу с диаграммой
подключает Mermaid из комплекта Docara (`vendor/mermaid/mermaid.min.js`, с
сайта, без внешних CDN). Страницы без диаграмм этот файл не загружают, а в
сборку он попадает, только если диаграмма есть хотя бы на одной странице.

В браузере Mermaid запускается с `securityLevel: 'strict'` и заменяет исходник
на SVG. Если JavaScript выключен, читатель видит исходник схемы. Если Mermaid
не смог разобрать схему, исходник остаётся на месте, а блок получает атрибут
`data-docara-render-error="diagram"`.
