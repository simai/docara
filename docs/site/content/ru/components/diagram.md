# Диаграмма

Диаграмма хранит схему Mermaid рядом с текстом статьи и показывает её исходник
в читаемом блоке. Это удобно для проверяемых потоков и связей, которые меняются
вместе с документацией.

## Общий пример

:::example {label="Общий пример"}
```markdown
:::diagram {engine=mermaid title="Цепочка сборки"}
flowchart LR
  Markdown --> Parser
  Parser --> HTML
:::
```
:::

## Параметры

`engine` сейчас принимает только `mermaid`. Параметр `title` задаёт доступное
название схемы; формулируйте его так, чтобы смысл был понятен без исходного кода.

## Вызов

```markdown
:::diagram {engine=mermaid title="Публикация документации"}
flowchart LR
  Author --> Build
  Build --> Verify
  Verify --> Publish
:::
```

Используйте поддерживаемый синтаксис Mermaid и короткие подписи узлов. Текущая
переносимая сборка сохраняет схему как доступный исходник и не загружает
дополнительный клиентский движок отображения.
