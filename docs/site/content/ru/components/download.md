# Скачивание

Блок скачивания показывает файл как понятное действие и заранее сообщает его
имя, формат, размер и, если нужно, контрольную сумму.

## Пример

:::example {label="Скачивание"}
```markdown
:::download {title="docara-mark.svg" format="SVG" file_size="1 КБ"}
[Скачать знак Docara](../../assets/docara-mark.svg)
:::
```
:::

## Разметка

```markdown
:::download {title="archive.zip" format="ZIP" file_size="4,8 МБ"}
[Скачать архив](../../files/archive.zip)
:::
```

- Внутри — ровно одна ссылка Markdown на файл. Без ссылки сборка
  останавливается.
- Текст ссылки — надпись на кнопке: назовите действие и файл.
- Параметры необязательные. Без них блок превращается в одну кнопку
  скачивания.

## Варианты

### Сведения о файле

`title`, `format`, `file_size` и `checksum` показываются рядом с кнопкой.
Указывайте только проверенные значения.

:::example {label="С контрольной суммой"}
```markdown
:::download {title="docara-mark.svg" format="SVG" file_size="1 КБ" checksum="SHA-256: 061e…fa90"}
[Скачать и проверить](../../assets/docara-mark.svg)
:::
```
:::

### Действие

`action=download` предлагает сохранить файл, `action=open` открывает его в
браузере — удобно для PDF и изображений.

:::example {label="Открыть в браузере"}
```markdown
:::download {title="docara-mark.svg" format="SVG" action=open}
[Открыть знак Docara](../../assets/docara-mark.svg)
:::
```
:::

## Доступность

- Кнопка — ссылка: она получает фокус клавишей Tab и срабатывает по Enter.
- Текст ссылки — её имя для программ экранного доступа. «Скачать архив
  документации», а не «Скачать».
- Формат и размер стоят рядом с кнопкой текстом, поэтому читатель знает, что
  загрузит, ещё до нажатия.

## Параметры

<!-- docara:component-parameters:start -->

| Параметр | Значения | По умолчанию | Что задаёт |
| --- | --- | --- | --- |
| `title` | строка | — | Название файла, которое видит читатель. Старое имя `name` принимается с предупреждением. |
| `format` | строка | — | Формат файла, например `PDF` или `ZIP`. |
| `file_size` | строка | — | Размер файла, например `2 МБ`. Старое имя `size` принимается с предупреждением. |
| `checksum` | строка | — | Контрольная сумма для проверки файла. |
| `action` | `download`, `open` | `download` | `download` — скачать файл, `open` — открыть его в браузере. |

<!-- docara:component-parameters:end -->
