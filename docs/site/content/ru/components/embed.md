# Встраиваемый материал

Блок показывает видео, карту или другой доверенный материал в рамке с
постоянными пропорциями. Внешний сайт загружается только после действия
читателя: до этого он не получает ни одного запроса.

## Пример

:::example {label="Встраиваемое видео"}
```markdown
:::embed {provider=video label="Внешняя демонстрация"}
[Открыть встроенный материал](https://www.youtube-nocookie.com/embed/dQw4w9WgXcQ)
:::
```
:::

## Разметка

```markdown
:::embed {provider=map ratio=4/3 label="Интерактивная карта"}
[Открыть карту](https://www.openstreetmap.org/export/embed.html)
:::
```

- Внутри — одна ссылка Markdown. Её адрес — что встроить, её текст — надпись
  на кнопке загрузки.
- Адрес проверяется при сборке. Неподходящий останавливает её с ошибкой
  `MARKDOWN_EMBED_ORIGIN_FORBIDDEN`.

## Варианты

### Поставщик

`provider` определяет, какие адреса принимаются:

| `provider` | Какой адрес принимается |
| --- | --- |
| `generic` | Только адрес этого же сайта: путь от корня, например `/demo/widget/` |
| `video` | Только `https`: `youtube.com`, `www.youtube.com`, `youtube-nocookie.com`, `www.youtube-nocookie.com`, `player.vimeo.com` |
| `map` | Только `https`: `openstreetmap.org`, `www.openstreetmap.org` |
| `external` | Любой адрес `https`, но только с `consent=required` |

:::example {label="Карта и внешний виджет"}
```markdown
:::embed {provider=map ratio=4/3 label="Интерактивная карта"}
[Открыть карту](https://www.openstreetmap.org/export/embed.html)
:::

:::embed {provider=external ratio=1/1 label="Внешний виджет"}
[Открыть внешний виджет](https://example.com/)
:::
```
:::

### Пропорции

`ratio` задаёт соотношение сторон рамки. Место под материал занято сразу, и
страница не прыгает, когда он загружается.

## Состояния

### До согласия

С `consent=required` вместо материала стоит кнопка загрузки. Нажатие
загружает рамку на этом месте.

### Сразу

`consent=none` загружает материал при открытии страницы. Это разрешено только
для адреса этого же сайта: видео, карта и внешний виджет всегда ждут действия
читателя.

## Доступность

- До загрузки на месте материала стоит кнопка с текстом ссылки: она получает
  фокус клавишей Tab.
- `label` — название рамки для программ экранного доступа. Его не видно на
  странице, но без него рамка остаётся безымянной: задавайте его всегда.
- Рамка изолирована: встроенный сайт не видит страницу документации.

## Параметры

<!-- docara:component-parameters:start -->

| Параметр | Значения | По умолчанию | Что задаёт |
| --- | --- | --- | --- |
| `provider` | `generic`, `video`, `map`, `external` | `generic` | Что встраивается: `generic` — страница, `video` — видео, `map` — карта, `external` — внешний сервис. |
| `id` | строка | — | Якорь блока на странице: на него можно сослаться как на `#id`. Латиница, цифры, точка, дефис и подчёркивание. |
| `ratio` | `1/1`, `4/3`, `3/2`, `16/9`, `21/9` | `16/9` | Соотношение сторон окна встраивания. |
| `label` | строка | `Embedded content` | Название встроенного материала для программ экранного доступа. Старое имя `title` принимается с предупреждением. |
| `consent` | `required`, `none` | `required` | `required` — материал загружается только после согласия читателя, `none` — сразу. |

<!-- docara:component-parameters:end -->
