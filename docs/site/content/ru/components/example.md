# Интерактивный пример

Блок показывает рядом готовый результат и его исходник. Читатель переключает
вкладки, проверяет поведение на разной ширине экрана и копирует точный вызов.

## Пример

:::example {label="Пример"}
```markdown
:badge[Готово]{variant=main scheme=success size=1/2}
```
:::

## Разметка

~~~markdown
:::example {label="Название результата"}
```markdown
:badge[Готово]{variant=main scheme=success}
```
:::
~~~

- Внутри — исходник примера в блоке кода: один блок `markdown` или блок
  `html` с необязательными `css` и `javascript`.
- `label` — подпись вкладки с результатом. Без неё вкладка называется
  «Пример» (строка `examples.example` из `lang.json`).
- Вместо исходника можно сослаться на общий пример проекта: `id="…"`.
  Смешивать оба способа нельзя.

## Варианты

### HTML, CSS и JavaScript

Для небольшого самостоятельного интерфейса объедините HTML с необязательными
CSS и JavaScript. Такой пример выполняется в изолированной рамке и не видит
страницу документации.

:::example {label="Интерактивный пример"}
```html
<button class="example-button" type="button">Нажмите</button>
<output class="example-result">Готово</output>
```
```css
:root { color-scheme: light dark; }
body { color: CanvasText; background: Canvas; }
.example-button { padding: .5rem 1rem; }
.example-result { margin-inline-start: 1rem; }
```
```javascript
document.querySelector('.example-button').addEventListener('click', () => {
  document.querySelector('.example-result').textContent = 'Выполнено';
});
```
:::

### Общий пример из проекта

Если пример нужен на нескольких страницах или во всех языках, храните его
один раз в корневой папке `examples/`:

```text
examples/
  utilities/
    animation-duration/
      index.html
      index.css
      index.js
      assets/
```

`index.html` обязателен, остальное — по необходимости. Путь папки становится
идентификатором:

```markdown
:::example {id="utilities/animation-duration" label="Результат"}
:::
```

Docara показывает только существующие вкладки и публикует нужные файлы с
учётом `base_url`. После изменения общего примера выполните полную сборку:
точечная сборка остановится, чтобы не оставить другие страницы со старой
версией.

### Способ показа

`preview` выбирает, где показывается результат:

- `auto` — Docara решает при сборке: Markdown и безопасный HTML без своих
  стилей и скриптов встраиваются прямо в страницу, остальное открывается в
  изолированной рамке;
- `inline` — прямо в странице. Если пример требует изоляции, сборка
  остановится с понятной ошибкой;
- `sandbox` — в изолированной рамке, когда важны свои стили, скрипты или
  независимое окружение.

Разметка с адаптивными утилитами (`sm:`, `md:`, `lg:`, `cq-md:` …) при `auto`
открывается в рамке: такие утилиты зависят от ширины окна, а встроенный
пример видел бы только ширину страницы.

:::example {label="Адаптивная карточка" preview=sandbox}
```html
<article class="adaptive-card">
  <strong>Карточка товара</strong>
  <span>Цена и действие меняют расположение на телефоне.</span>
  <button type="button">В корзину</button>
</article>
```
```css
.adaptive-card {
  display: grid;
  grid-template-columns: 1fr auto;
  gap: 1rem;
  align-items: center;
  padding: 1rem;
  border: 1px solid currentColor;
  border-radius: 1rem;
}

.adaptive-card button {
  grid-column: 2;
  grid-row: 1 / span 2;
}

@media (max-width: 600px) {
  .adaptive-card {
    grid-template-columns: 1fr;
  }

  .adaptive-card button {
    grid-column: 1;
    grid-row: auto;
  }
}
```
:::

Выбранный способ и его причина записываются в
`build_<environment>.docara/examples.json` и видны через `inspect page`.

### Что встраивается в страницу

Встроенный пример выглядит так же, как на настоящей странице: выпадающие
списки и подсказки открываются поверх документации. Стили текста
документации на него не действуют. Компоненты Framework, которые использует
разметка, подключаются сами.

Во встроенном HTML допускаются:

- атрибуты `data-*`, кроме `data-docara-*`; значение не может начинаться со
  схем `javascript:`, `vbscript:` или `data:`;
- `id` в kebab-case хотя бы с одним дефисом, не начинающийся с `docara-`;
- атрибут `slot` с простым значением в kebab-case;
- элемент `form` без `action`, `method`, `target`, `enctype` и `name`:
  отправку такой формы Docara отменяет;
- у Smart-элементов `sf-*` — атрибуты, которые закреплённая версия Framework
  объявляет для этого тега.

Никогда не встраиваются атрибуты `on*`, `href`, `src`, `srcdoc`, `style`,
`action`, `formaction`, `form`, `autofocus` и `contenteditable`, а также
элементы `script`, `style`, `link`, `iframe`, `a`, `img` и другие вне
списка. Такой пример остаётся в рамке.

`id` встроенного примера живёт в общем пространстве страницы. Совпадение с
другим примером или элементом оболочки останавливает сборку ошибкой
`MARKDOWN_EXAMPLE_INLINE_ID_DUPLICATE`. Переименуйте `id` или задайте
`preview=sandbox`.

## Состояния

### Проверка на разной ширине

Кнопка с устройствами в шапке примера открывает его на весь экран с выбором
ширины: компьютер — 1280 px или ширина экрана, если он уже, планшет — 768 px,
телефон — 390 px. Меняется настоящая ширина изолированной рамки, поэтому
адаптивные правила срабатывают так же, как в отдельном окне. У встроенного
примера рамка загружается только при открытии проверки, а до готовности
показывается обычный результат. Кнопка выхода и Escape возвращают пример на
место.

### Перенос длинных строк

На вкладке с исходником кнопка включает визуальный перенос длинных строк.
Текст исходника и копирование не меняются. Выбор общий для всех примеров и
блоков кода на странице и сохраняется в браузере.

Обе кнопки можно отключить для сайта, раздела или страницы:

```json
{
  "examples": {
    "fullscreen": false,
    "wrap": false
  }
}
```

или для одного блока: `:::example {fullscreen=false wrap=false}`.

### Загрузка

Изолированная рамка загружается, когда приближается к экрану (за 600 px), а
рамка в скрытой вкладке ждёт, пока вкладку откроют. Примеры ниже первого
экрана не замедляют загрузку страницы. Рамка получает тему, направление
письма, шрифты и цветовые токены страницы, поэтому выглядит как окружающая
документация.

## Доступность

- Вкладки примера переключаются стрелками; Tab переводит фокус на кнопки
  копирования, переноса и проверки ширины.
- Рамка результата называется подписью `label`: задавайте понятную подпись.
- Режим проверки ширины — диалог: фокус остаётся в нём, Escape закрывает его
  и возвращает фокус на кнопку.

## Параметры

<!-- docara:component-parameters:start -->

| Параметр | Значения | По умолчанию | Что задаёт |
| --- | --- | --- | --- |
| `id` | строка | — | Идентификатор общего примера из папки `examples/` проекта. |
| `label` | строка | `Example` | Подпись вкладки с результатом. |
| `preview` | `auto`, `inline`, `sandbox` | `auto` | Как показать результат: `auto` — выбрать по содержимому, `inline` — прямо на странице, `sandbox` — в изолированном окне. |
| `fullscreen` | `true`, `false` | — | Кнопка проверки на ширине компьютера, планшета и телефона. |
| `wrap` | `true`, `false` | — | Кнопка переноса длинных строк в исходном коде. |
