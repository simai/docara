# Иллюстрация

Иллюстрация показывает одно изображение с обязательным альтернативным текстом
и необязательной подписью. Пропорции можно закрепить без искажения файла.

## Общий пример

:::example {label="Общий пример"}
```markdown
:::figure {ratio=16/9 fit=cover}
![Интерфейс документации](../../assets/docara-screen.png)

Широкая иллюстрация заполняет область 16:9.
:::
```
:::

## Соотношение сторон

| Значение | Назначение |
| --- | --- |
| `auto` | Исходные пропорции · **По умолчанию** |
| `1/1` | Квадрат |
| `4/3` | Классическая схема или снимок |
| `3/2` | Фотография |
| `16/9` | Широкая иллюстрация |
| `21/9` | Панорама |

## Заполнение

`fit=cover` заполняет всю область и при необходимости обрезает края.
`fit=contain` показывает изображение целиком и подходит для знаков и схем.

:::example {label="Показать целиком"}
```markdown
:::figure {ratio=1/1 fit=contain}
![Знак Docara](../../assets/docara-mark.svg)

Знак показан целиком внутри квадратной области.
:::
```
:::

## Вызов

```markdown
:::figure {ratio=4/3 fit=cover}
![Схема сборки](../../assets/docara-flow.png)

Короткая подпись дополняет изображение.
:::
```

Альтернативный текст описывает смысл изображения, а не его оформление.
Подпись не заменяет alt-текст; не используйте блок для нескольких изображений.
