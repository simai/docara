# Сноски и источники

Сноска добавляет проверяемое пояснение или источник, не прерывая основной
текст. Читатель переходит к примечанию и может вернуться к месту ссылки.

## Общий пример

:::example {label="Общий пример"}
```markdown
Docara собирает документацию из Markdown.[^source]

[^source]: Руководство проекта, актуальная версия и адрес публикации.
```
:::

## Как назвать ссылку

Метка между `[^` и `]` должна быть короткой и устойчивой: `source`, `api` или
номер. Одна метка связывает ссылку в тексте с одним определением ниже.

| Часть | Назначение |
| --- | --- |
| `[^source]` | Ссылка в основном тексте |
| `[^source]: ...` | Текст примечания или описание источника |
| Адрес публикации | Позволяет читателю проверить утверждение |

## Вызов

```markdown
Утверждение, которое требует пояснения.[^note]

[^note]: Автор, название, версия и ссылка.
```

Сноска не заменяет понятный основной текст. Указывайте автора, название,
версию или дату и доступный адрес, если утверждение опирается на внешний
источник.
