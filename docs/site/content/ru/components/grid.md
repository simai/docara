# Сетка

Сетка располагает самостоятельные блоки в адаптивных колонках. На узком
экране элементы автоматически складываются в одну колонку в исходном порядке.

## Общий пример

:::example {label="Общий пример"}
```markdown
::::grid {columns=3 gap=2}
:::card
#### Markdown

Понятный исходный формат.
:::
:::card
#### JSON

Проверяемые настройки.
:::
:::card
#### HTML

Готовый статический результат.
:::
::::
```
:::

## Колонки

`columns` задаёт максимальное число колонок на широком экране: от `1` до `4`.
Количество дочерних блоков может отличаться от этого значения.

:::example {label="Две колонки"}
```markdown
::::grid {columns=2 gap=2}
:::card
#### Содержание

Первый самостоятельный блок.
:::
:::card
#### Композиция

Второй самостоятельный блок.
:::
::::
```
:::

## Расстояние

`gap` принимает значения от `0` до `4` по общей шкале SIMAI Framework.
Выбирайте один шаг для всей группы, чтобы карточки сохраняли ровный ритм.

## Вызов

```markdown
::::grid {columns=3 gap=2}
:::card
#### Первый блок

Содержимое.
:::
:::card
#### Второй блок

Содержимое.
:::
::::
```

Сетка отвечает только за расположение. Смысл, заголовки и доступность остаются
ответственностью вложенных компонентов; не меняйте порядок ради внешнего вида.
