# Заголовки и текст

Заголовки делят статью на понятные разделы, а обычный Markdown выделяет
важные слова без ручной HTML-разметки.

## Общий пример

:::example {label="Общий пример"}
```markdown
## Настройка проекта

Сначала укажите **обязательные параметры**, затем добавьте *полезные
пояснения*. Устаревшую рекомендацию можно временно отметить как
~~неактуальную~~.
```
:::

## Уровни заголовков

| Запись | Назначение |
| --- | --- |
| `#` | Название страницы; используется один раз |
| `##` | Основной раздел |
| `###` | Подраздел внутри основного раздела |
| `####`–`######` | Редкая дополнительная детализация |

Не пропускайте уровни только ради размера шрифта: внешний вид задаёт тема, а
уровень описывает структуру документа.

## Выделение текста

```markdown
**важный текст**
*смысловой акцент*
~~устаревшая формулировка~~
`имя_параметра`
```

Жирное начертание подходит для ключевого результата, курсив — для короткого
акцента, зачёркивание — для явно устаревшей формулировки, а inline-код — для
команд, файлов и значений. Произвольный HTML вместо Markdown не используйте.
