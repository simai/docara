# Первый экран

Первый экран кратко объясняет ценность страницы или продукта и предлагает
следующий шаг. Обычно он открывает лендинг, а не повторяется внутри статьи.
Hero владеет смыслом H1, описания, действий и изображения, а outer width,
container, фон и overlay строит общая Surface presentation. Автор не пишет
Surface вокруг Hero: double wrapping не поддерживается.

Без фонового изображения Hero использует лёгкую токенизированную заливку с
полупрозрачными акцентами. Она автоматически следует светлой и тёмной теме;
проекту не требуется добавлять собственные цвета или CSS.

## Общий пример

:::example {label="Общий пример"}
```markdown
:::hero {layout=split}
# Документация, которую удобно создавать и читать

Docara превращает Markdown и проверенные JSON-настройки в быстрый статический сайт.

[Открыть быстрый старт](../../start/)

![Страница документации и её компоненты](../../assets/hero-split.webp)
:::
```
:::

## Компоновка

Параметр `layout` выбирает расположение текста и изображения.

| Значение | Назначение |
| --- | --- |
| `split` | Текст и изображение в двух колонках на широком экране · **По умолчанию** |
| `centered` | Текст и действие по центру |
| `compact` | Короткое введение без изображения |

`padding=lg|xl|2xl` регулирует внутренние отступы независимо от варианта.
`compact` по умолчанию использует `lg`, остальные варианты — `xl`. На узком
экране оболочка всё равно уменьшает отступ до безопасного мобильного значения.

| Значение | Отступ сверху и снизу |
| --- | --- |
| `lg` | Шаг 3 SIMAI Framework: 16 px на узком экране, 24 px от 960 px |
| `xl` | Шаг 4 SIMAI Framework: 24 px на узком экране, 32 px от 960 px |
| `2xl` | Растёт вместе с шириной окна: 48 px на экране до 400 px, затем плавно до 112 px на экране от 1470 px |

`2xl` делает первый экран лендинга объёмным без собственного CSS. Отступ
меняется плавно, без скачков на брейкпоинтах: его границы — токены отступов
Framework `--sf-d2` и `--sf-e4`. Кнопка остановки фонового эффекта
помещается в нижний отступ `2xl`, поэтому Hero с эффектом не становится
выше.

:::example {label="Высокий первый экран"}
```markdown
:::hero {layout=centered padding=2xl}
# Документация, которую удобно читать

Высокий первый экран лендинга: отступ растёт вместе с шириной окна.

[Открыть быстрый старт](../../start/)
:::
```
:::

## Изображение

`media` задаёт семантику единственного Markdown-изображения:

| Значение | Контракт |
| --- | --- |
| `auto` | Совместимый режим по умолчанию: сохраняет прежнее поведение Hero |
| `side` | Одно смысловое изображение с непустым alt; только `layout=split` |
| `background` | Одно декоративное локальное изображение с пустым alt |
| `none` | Изображение запрещено |

Явный смысловой side-media вариант:

```markdown
:::hero {layout=split media=side}
# Документация, которую удобно читать

Одно смысловое изображение остаётся частью содержания.

![Светлая страница документации перед двумя тёмными](/assets/hero-side.webp)
:::
```

Фоновый режим использует уже написанное Markdown-изображение — отдельного
`image` или `background_image` свойства у Hero нет. Файл должен существовать
в `assets/`; внешние URL, data URI, переходы по каталогам, symlink и hardlink
отклоняются до рендера.

:::example {label="Фоновое изображение"}
```markdown
:::hero {media=background background_fit=cover background_x=right background_y=center overlay=dark overlay_strength=strong}
# Документация без лишней сложности

Содержимое остаётся читаемым поверх токенизированного затемнения.

![](/assets/hero-backdrop.webp)
:::
```
:::

Параметры `background_fit=cover|contain|auto`,
`background_x=left|center|right`, `background_y=top|center|bottom`,
`overlay=light|dark` и `overlay_strength=soft|medium|strong` доступны только
при `media=background`. Их значения по умолчанию: `cover`, `center`, `center`,
`dark` и `medium`.

:::example {label="Компактный вариант"}
```markdown
:::hero {layout=compact padding=xl}
# Короткое введение

Компактный вариант подходит для внутренней страницы без изображения.
:::
```
:::

:::example {label="Вариант по центру"}
```markdown
:::hero {layout=centered}
# Начните с пустого каталога

Одна команда создаст проверяемую структуру сайта.

[Открыть быстрый старт](../../start/)
:::
```
:::

## Фоновый эффект

Вместо фоновой картинки первый экран может показывать анимацию из каталога
эффектов SIMAI. Каталог подключается один раз в `docara.json`, а эффект
выбирается параметром `effect`:

```markdown
:::hero {layout=centered padding=2xl effect=constellation-net}
# Документация, которую удобно читать

Эффект рисуется под текстом и не мешает читать.
:::
```

`effect_theme` выбирает светлую или тёмную версию эффекта, `effect_settings`
задаёт его настройки. Пока эффект движется, в нижнем отступе Hero есть кнопка
паузы; при уменьшении движения в системе эффект показывает неподвижный кадр.
Эффект нельзя сочетать с `media=background`.

Как подключить каталог, выбрать эффект, что нужно хостингу с
Content-Security-Policy и какие ошибки бывают, описано на странице
[Фоновые эффекты](/ru/components/effects/).

## Содержимое

Блок начинается с одного H1, затем содержит один или два абзаца. После них
можно добавить до двух безопасных ссылок-действий и одно изображение. Для
`side` его alt осмысленный, для `background` — пустой, а `none` запрещает
изображение.

## Вызов

```markdown
:::hero {layout=compact}
# Короткий заголовок

Одно понятное объяснение ценности страницы.
:::
```

Не вкладывайте в первый экран другие типизированные директивы или
Smart-компоненты. Для объявления внутри обычной статьи используйте баннер.
Не оборачивайте Hero в Surface: это не добавляет ширины и отклоняется как
недопустимое вложение.
