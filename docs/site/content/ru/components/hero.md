# Первый экран

Первый экран кратко объясняет ценность страницы или продукта и предлагает
следующий шаг. Он открывает лендинг и не повторяется внутри статьи. Блок сам
растягивается на всю ширину окна и задаёт фон, поэтому оборачивать его в
[оформленную полосу](../surface/) не нужно.

## Пример

:::example {label="Первый экран"}
```markdown
:::hero
# Документация, которую удобно создавать и читать

Docara превращает Markdown и проверенные JSON-настройки в быстрый статический сайт.

[Открыть быстрый старт](../../start/)

![Страница документации и её компоненты](../../assets/hero-split.webp)
:::
```
:::

## Разметка

```markdown
:::hero
# Короткий заголовок

Одно-два предложения о ценности страницы.

[Главное действие](/ru/start/)

![Описание изображения](/assets/hero.webp)
:::
```

- Блок начинается с одного заголовка `#`, затем один или два абзаца.
- После них — до двух ссылок-действий и одно изображение, в этом порядке.
- Другие блоки Docara и Smart-компоненты внутрь не вкладываются. Обёртка в
  оформленную полосу отклоняется: первый экран уже управляет шириной и
  фоном.

Без фонового изображения и эффекта первый экран залит лёгким фоном с
полупрозрачными акцентами. Он сам следует светлой и тёмной теме.

## Варианты

### Компоновка

`layout=split` ставит текст и изображение в две колонки на широком экране,
`centered` выравнивает всё по центру, `compact` даёт короткое введение без
изображения.

:::example {label="По центру и компактный"}
```markdown
:::hero {layout=centered}
# Начните с пустого каталога

Одна команда создаст проверяемую структуру сайта.

[Открыть быстрый старт](../../start/)
:::

:::hero {layout=compact}
# Короткое введение

Компактный вариант подходит для внутренней страницы без изображения.
:::
```
:::

### Высота

`padding` задаёт отступы сверху и снизу. По умолчанию у `compact` — `lg`, у
остальных — `xl`.

| Значение | Отступ сверху и снизу |
| --- | --- |
| `lg` | Шаг 3 SIMAI Framework: 16 px на узком экране, 24 px от 960 px |
| `xl` | Шаг 4 SIMAI Framework: 24 px на узком экране, 32 px от 960 px |
| `2xl` | Растёт вместе с шириной окна: 48 px на экране до 400 px, затем плавно до 112 px на экране от 1470 px |

`2xl` делает первый экран лендинга объёмным без своего CSS. Кнопка паузы
фонового эффекта помещается в нижний отступ `2xl`, поэтому блок с эффектом
не становится выше.

:::example {label="Высокий первый экран"}
```markdown
:::hero {layout=centered padding=2xl}
# Документация, которую удобно читать

Высокий первый экран лендинга: отступ растёт вместе с шириной окна.

[Открыть быстрый старт](../../start/)
:::
```
:::

### Изображение

`media` задаёт роль изображения:

| Значение | Что значит |
| --- | --- |
| `auto` | Изображение необязательно; если оно есть, стоит рядом с текстом |
| `side` | Одно смысловое изображение рядом с текстом, с описанием; только для `layout=split` |
| `background` | Одно декоративное изображение фоном, с пустым описанием `![](…)` |
| `none` | Без изображения |

Фоновое изображение берётся из того же Markdown-изображения в конце блока.
Файл должен лежать в `assets/` проекта: внешние адреса и пути за пределы
проекта отклоняются при сборке. Положение фона, затемнение и его силу задают
`background_fit`, `background_x`, `background_y`, `overlay` и
`overlay_strength` — они работают только с `media=background`.

:::example {label="Фоновое изображение"}
```markdown
:::hero {media=background background_x=right overlay=dark overlay_strength=strong}
# Документация без лишней сложности

Текст остаётся читаемым поверх затемнения.

![](/assets/hero-backdrop.webp)
:::
```
:::

### Фоновый эффект

Вместо фоновой картинки первый экран может показывать анимацию из каталога
эффектов SIMAI. Каталог подключается один раз в `docara.json`, эффект
выбирается параметром `effect`. Эффект не сочетается с `media=background`.

```markdown
:::hero {layout=centered padding=2xl effect=constellation-net}
# Документация, которую удобно читать

Эффект рисуется под текстом и не мешает читать.
:::
```

Как подключить каталог, выбрать эффект и что нужно хостингу с
Content-Security-Policy, описано на странице
[«Фоновые эффекты»](../effects/).

## Состояния

### Пауза и уменьшение движения

Пока эффект движется, в нижнем отступе есть кнопка паузы. Если в системе
включено уменьшение движения, эффект показывает неподвижный кадр.

## Доступность

- Заголовок первого экрана — главный заголовок страницы `<h1>`: на странице
  он один.
- Ссылки-действия — обычные ссылки: Tab и Enter. Пишите в них действие:
  «Открыть быстрый старт».
- Смысловому изображению (`side`) нужно описание — без него сборка
  останавливается. Фоновое изображение — украшение с пустым описанием.
- Затемнение (`overlay`) держит контраст текста на фоне. Проверяйте
  читаемость в светлой и тёмной теме.

## Параметры

<!-- docara:component-parameters:start -->

| Параметр | Значения | По умолчанию | Что задаёт |
| --- | --- | --- | --- |
| `layout` | `split`, `centered`, `compact` | `split` | Компоновка: `split` — текст и изображение рядом, `centered` — всё по центру, `compact` — невысокий блок. Старое имя `variant` принимается с предупреждением. |
| `padding` | `lg`, `xl`, `2xl` | — | Внутренние отступы сверху и снизу. |
| `media` | `auto`, `side`, `background`, `none` | `auto` | Где изображение: `auto` — по компоновке, `side` — рядом с текстом, `background` — фоном, `none` — без изображения. |
| `background_fit` | `cover`, `contain`, `auto` | `cover` | Как фоновое изображение заполняет блок. |
| `background_x` | `left`, `center`, `right` | `center` | Положение фонового изображения по горизонтали. |
| `background_y` | `top`, `center`, `bottom` | `center` | Положение фонового изображения по вертикали. |
| `overlay` | `light`, `dark` | `dark` | Затемнение или осветление поверх фона, чтобы текст читался. |
| `overlay_strength` | `soft`, `medium`, `strong` | `medium` | Сила затемнения или осветления. |
| `effect` | строка | — | Имя фонового эффекта SIMAI Framework. |
| `effect_theme` | `auto`, `dark`, `light` | `auto` | Тема эффекта: по теме страницы, всегда тёмная или всегда светлая. |
| `effect_settings` | строка | — | Настройки эффекта в виде JSON. |

<!-- docara:component-parameters:end -->
