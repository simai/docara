# Первый экран

Первый экран кратко объясняет ценность страницы или продукта и предлагает
следующий шаг. Обычно он открывает лендинг, а не повторяется внутри статьи.
Hero владеет смыслом H1, описания, действий и изображения, а outer width,
container, фон и overlay строит общая Surface presentation. Автор не пишет
Surface вокруг Hero: double wrapping не поддерживается.

Без фонового изображения Hero использует лёгкую токенизированную заливку с
полупрозрачными акцентами. Она автоматически следует светлой и тёмной теме;
проекту не требуется добавлять собственные цвета или CSS.

## Общий пример

:::example {label="Общий пример"}
```markdown
:::hero {variant=split}
# Документация, которую удобно создавать и читать

Docara превращает Markdown и проверенные JSON-настройки в быстрый статический сайт.

[Открыть быстрый старт](../../start/)

![Компоненты Docara](../../assets/docara-components.png)
:::
```
:::

## Компоновка

| Значение | Назначение |
| --- | --- |
| `split` | Текст и изображение в двух колонках на широком экране · **По умолчанию** |
| `centered` | Текст и действие по центру |
| `compact` | Короткое введение без изображения |

`padding=lg|xl|2xl` регулирует внутренние отступы независимо от варианта.
`compact` по умолчанию использует `lg`, остальные варианты — `xl`. На узком
экране оболочка всё равно уменьшает отступ до безопасного мобильного значения.

| Значение | Отступ сверху и снизу |
| --- | --- |
| `lg` | Шаг 3 SIMAI Framework: 16 px на узком экране, 24 px от 960 px |
| `xl` | Шаг 4 SIMAI Framework: 24 px на узком экране, 32 px от 960 px |
| `2xl` | Растёт вместе с шириной окна: 48 px на экране до 400 px, затем плавно до 112 px на экране от 1470 px |

`2xl` делает первый экран лендинга объёмным без собственного CSS. Отступ
меняется плавно, без скачков на брейкпоинтах: его границы — токены отступов
Framework `--sf-d2` и `--sf-e4`. Кнопка остановки фонового эффекта
помещается в нижний отступ `2xl`, поэтому Hero с эффектом не становится
выше.

:::example {label="Высокий первый экран"}
```markdown
:::hero {variant=centered padding=2xl}
# Документация, которую удобно читать

Высокий первый экран лендинга: отступ растёт вместе с шириной окна.

[Открыть быстрый старт](../../start/)
:::
```
:::

## Изображение

`media` задаёт семантику единственного Markdown-изображения:

| Значение | Контракт |
| --- | --- |
| `auto` | Совместимый режим по умолчанию: сохраняет прежнее поведение Hero |
| `side` | Одно смысловое изображение с непустым alt; только `variant=split` |
| `background` | Одно декоративное локальное изображение с пустым alt |
| `none` | Изображение запрещено |

Явный смысловой side-media вариант:

```markdown
:::hero {variant=split media=side}
# Документация, которую удобно читать

Один смысловой скриншот остаётся частью содержания.

![Интерфейс документации](/assets/docara-screen.png)
:::
```

Фоновый режим использует уже написанное Markdown-изображение — отдельного
`image` или `background_image` свойства у Hero нет. Файл должен существовать
в `assets/`; внешние URL, data URI, переходы по каталогам, symlink и hardlink
отклоняются до рендера.

```markdown
:::hero {media=background background_fit=cover background_x=center background_y=center overlay=dark overlay_strength=medium}
# Документация без лишней сложности

Содержимое остаётся читаемым поверх токенизированного затемнения.

![](/assets/docara-screen.png)
:::
```

Параметры `background_fit=cover|contain|auto`,
`background_x=left|center|right`, `background_y=top|center|bottom`,
`overlay=light|dark` и `overlay_strength=soft|medium|strong` доступны только
при `media=background`. Их значения по умолчанию: `cover`, `center`, `center`,
`dark` и `medium`.

:::example {label="Компактный вариант"}
```markdown
:::hero {variant=compact padding=xl}
# Короткое введение

Компактный вариант подходит для внутренней страницы без изображения.
:::
```
:::

:::example {label="Вариант по центру"}
```markdown
:::hero {variant=centered}
# Начните с пустого каталога

Одна команда создаст проверяемую структуру сайта.

[Открыть быстрый старт](../../start/)
:::
```
:::

## Фоновый эффект

Первый экран может рисовать фоновый эффект из каталога эффектов SIMAI
Framework. Эффект подключает Framework (`SF.Effects`): Docara только
записывает в секцию Hero атрибуты `data-sf-effect`, `data-sf-effect-theme` и
`data-sf-effect-settings`, а загрузчик Framework находит секцию, проверяет
файлы эффекта по индексу каталога и рисует его под содержимым.

```markdown
:::hero {variant=centered effect="aurora-curtain" effect_theme=auto effect_settings='{"speed": 80}'}
# Документация, которую удобно читать

Эффект рисуется под текстом и не мешает читать.
:::
```

| Параметр | Значение |
| --- | --- |
| `effect` | Идентификатор эффекта в каталоге (`aurora-curtain`: строчные латинские буквы, цифры и дефис, от 2 до 41 символа) или `https`-адрес его `effect.json` внутри каталога. |
| `effect_theme` | `auto` — как у страницы (по умолчанию), `dark` или `light`. |
| `effect_settings` | JSON-объект сохранённых настроек эффекта. Значение пишите в одинарных кавычках. |

Тему области задаёт Framework: секция получает класс `theme-dark` или
`theme-light` той схемы, которую эффект действительно рисует, и текст Hero
следует за ней. Docara даёт такой секции фон `--sf-surface-0` и цвет текста
`--sf-on-surface` этой темы, поэтому текст читается и пока эффект загружается.
Если эффект не умеет рисовать нужную схему, Framework скрывает его, а секция
получает тему страницы.

Каталог задаётся один раз для сайта в `docara.json`; сборка записывает его в
`SF_BOOT_CONFIG.effects`:

```json
{
  "effects": {
    "catalogue": "https://cdn.jsdelivr.net/gh/simai/ui-effects@<commit>/",
    "index": "catalogue/index.json",
    "index_sha256": "<64 hex>"
  }
}
```

`catalogue` — адрес каталога, закреплённый на коммите, а не на ветке.
`index` и `index_sha256` необязательны: путь к индексу внутри каталога (по
умолчанию `catalogue/index.json`) и его SHA-256, если индекс тоже нужно
проверять.

Сборка остановится, если:

- значение `effect`, `effect_theme` или `effect_settings` не проходит проверку
  (`MARKDOWN_HERO_EFFECT_INVALID`, `MARKDOWN_COMPONENT_ATTRIBUTE_VALUE_INVALID`,
  `MARKDOWN_HERO_EFFECT_SETTINGS_INVALID`);
- `effect_theme` или `effect_settings` заданы без `effect`
  (`MARKDOWN_HERO_EFFECT_REQUIRED`);
- эффект сочетается с `media=background` (`MARKDOWN_HERO_EFFECT_MEDIA_CONFLICT`):
  фоном служит либо эффект, либо изображение;
- в `docara.json` нет `effects.catalogue` (`EFFECTS_CATALOGUE_REQUIRED`);
- адрес эффекта лежит вне каталога (`EFFECTS_OUTSIDE_CATALOGUE`): Docara
  собирает только эффекты каталога. Сам Framework запустил бы чужой эффект
  в изолированном фрейме (`SF_BOOT_CONFIG.effects.foreign`), но Docara этот
  режим не настраивает.

Пока эффект рисуется, в нижнем отступе Hero, у правого края (в RTL — у
левого), есть кнопка «Остановить фоновую анимацию». Она стоит ниже текста и
изображения и не закрывает их даже на телефоне. Отступ `2xl` вмещает кнопку,
и высота Hero не меняется. Отступы `lg` и `xl` ниже кнопки, поэтому у Hero
с эффектом нижний отступ становится высотой кнопки плюс 8 px сверху и снизу:
52 px на узком экране, 56 px от 960 px. Кнопка останавливает и снова
запускает эффект, а выбор запоминается в браузере читателя для всего сайта.
Если в системе включено уменьшение движения, Framework рисует один
неподвижный кадр, кнопка не показывается и отступ Hero остаётся своим.

Эффекты работают с парой SIMAI Framework, в которой есть `SF.Effects`:
`ui-08c07b3e938a` или новее. Docara поставляется с такой парой
(`ui-32c7a64e4575`), и сайты с lock прежних версий Docara собираются с ней же.
С другой, более ранней парой атрибуты остаются в разметке, но эффект не
рисуется, а Hero выглядит как без эффекта.

## Содержимое

Блок начинается с одного H1, затем содержит один или два абзаца. После них
можно добавить до двух безопасных ссылок-действий и одно изображение. Для
`side` его alt осмысленный, для `background` — пустой, а `none` запрещает
изображение.

## Вызов

```markdown
:::hero {variant=compact}
# Короткий заголовок

Одно понятное объяснение ценности страницы.
:::
```

Не вкладывайте в первый экран другие типизированные директивы или
Smart-компоненты. Для объявления внутри обычной статьи используйте баннер.
Не оборачивайте Hero в Surface: это не добавляет ширины и отклоняется как
недопустимое вложение.
