# Изолированный HTML

Блок показывает явно доверенный HTML внутри sandboxed iframe. Разметка не
получает доступ к странице документации и не может выполнять скрипты.

## Общий пример

:::example {label="Общий пример"}
````markdown
:::html
```html
<p><strong>Изолированный HTML</strong> без доступа к странице документации.</p>
```
:::
````
:::

## Рабочий результат

:::html
```html
<article>
  <h2>Самостоятельный фрагмент</h2>
  <p>Разметка отображается отдельно от интерфейса документации.</p>
</article>
```
:::

## Вызов

~~~markdown
:::html
```html
<p>Доверенный статический фрагмент.</p>
```
:::
~~~

Внутри блока должен быть ровно один фрагмент кода с языком `html`. Других
параметров у блока нет.

## Как работает изоляция

Docara помещает разметку в отдельный документ внутри рамки `iframe` с пустым
атрибутом `sandbox`. Браузер применяет к такой рамке все ограничения сразу:

- скрипты не выполняются, а формы не отправляются;
- разметка не видит страницу документации, её стили и данные читателя;
- рамка не может открыть окно или перейти на другую страницу.

Рамка загружается, только когда читатель доводит страницу до неё. Стили сайта
внутрь не попадают, поэтому фрагмент выглядит так, как его написали.

Используйте блок только для проверенной статической разметки. Для обычного
текста, ссылок, изображений и компонентов выбирайте Markdown. Если внутри нет
фрагмента `html` или их несколько, сборка останавливается с ошибкой
`MARKDOWN_HTML_FENCE_REQUIRED`.
