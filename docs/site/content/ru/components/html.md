# Изолированный HTML

Блок показывает фрагмент HTML в изолированной рамке. Разметка не видит
страницу документации и не выполняет скрипты. Выбирайте его, только когда
нужного нельзя записать в Markdown.

## Пример

:::example {label="Изолированный HTML"}
````markdown
:::html
```html
<article>
  <h2>Самостоятельный фрагмент</h2>
  <p>Разметка отображается отдельно от интерфейса документации.</p>
</article>
```
:::
````
:::

## Разметка

~~~markdown
:::html
```html
<p>Доверенный статический фрагмент.</p>
```
:::
~~~

- Внутри — ровно один блок кода с языком `html`. Если его нет или их
  несколько, сборка останавливается с ошибкой `MARKDOWN_HTML_FENCE_REQUIRED`.
- Стили сайта внутрь не попадают: фрагмент выглядит так, как его написали.

## Варианты

У блока нет параметров оформления.

## Состояния

### Изоляция

Docara помещает разметку в отдельный документ внутри рамки `iframe` с
пустым атрибутом `sandbox`. Браузер применяет к такой рамке все ограничения
сразу:

- скрипты не выполняются, формы не отправляются;
- разметка не видит страницу документации, её стили и данные читателя;
- рамка не может открыть окно или перейти на другую страницу.

Рамка загружается, только когда читатель доходит до неё.

## Доступность

- Рамка называется «Пример HTML» на русской странице и «HTML example» на
  странице на другом языке. Если фрагмент важен для понимания, опишите его в
  тексте рядом.
- Внутри рамки работают обычные правила HTML: заголовки, описания
  изображений, подписи полей пишите в самом фрагменте.
- Для текста, ссылок, изображений и компонентов выбирайте Markdown: его
  читают поиск, оглавление и программы экранного доступа.
