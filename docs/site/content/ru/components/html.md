# Изолированный HTML

Блок показывает явно доверенный HTML внутри sandboxed iframe. Разметка не
получает доступ к странице документации и не может выполнять скрипты.

## Общий пример

:::example {label="Общий пример"}
````markdown
:::html
```html
<p><strong>Изолированный HTML</strong> без доступа к странице документации.</p>
```
:::
````
:::

## Рабочий результат

:::html
```html
<article>
  <h2>Самостоятельный фрагмент</h2>
  <p>Разметка отображается отдельно от интерфейса документации.</p>
</article>
```
:::

## Вызов

~~~markdown
:::html
```html
<p>Доверенный статический фрагмент.</p>
```
:::
~~~

Используйте только проверенную статическую разметку. Для обычного текста,
ссылок, изображений и компонентов выбирайте Markdown; скрипты намеренно
запрещены sandbox-контрактом.
