# Медиа

Картинки, видео, файлы для скачивания и логотипы.

| Компонент | Для чего |
| --- | --- |
| [Иллюстрация](/ru/components/images-and-files/figure/) | Картинка с подписью и заданными пропорциями |
| [Текст с изображением](/ru/components/images-and-files/media/) | Короткое пояснение рядом с картинкой |
| [Встраиваемый материал](/ru/components/images-and-files/embed/) | Видео, карта или внешняя страница с согласием читателя |
| [Скачивание](/ru/components/images-and-files/download/) | Файл для скачивания с форматом, размером и контрольной суммой |
| [Логотипы и участники](/ru/components/images-and-files/logos/) | Ряд логотипов партнёров, продуктов или участников |

## Как выбрать

Одна картинка с подписью — это иллюстрация, а короткое пояснение рядом с картинкой —
текст с изображением. Видео, карту или внешнюю страницу встраивайте только после
согласия читателя: так сайт не загружает чужое без спроса. Файл для скачивания
показывайте с форматом, размером и контрольной суммой, а ряд логотипов партнёров
или участников соберите отдельным блоком.
