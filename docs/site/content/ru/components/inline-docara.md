# Inline-компоненты Docara

Inline-компонент добавляет короткий визуальный элемент внутрь абзаца, не разрывая поток чтения.

```markdown
Сборка :badge[готова]{type=main scheme=success size=1/2} к проверке.
```
:::

## Props и доступность

Параметры разбираются типизированно до шаблона. Текст остаётся доступным именем; цвет не должен быть единственным носителем смысла.

## Ошибка

Неизвестный alias, prop или небезопасное значение завершается fail-closed диагностикой с route, относительным source-файлом, line и column. Inline HTML и произвольный callback не являются способом расширения.
