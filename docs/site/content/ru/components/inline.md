# Inline и действия

Мелкие элементы внутри строки текста: бейджи, кнопки-ссылки, значки и клавиши.

| Компонент | Для чего |
| --- | --- |
| [Бейдж](/ru/components/inline/badge/) | Короткая метка статуса или версии внутри текста |
| [Кнопка-ссылка](/ru/components/inline/button/) | Ссылка, оформленная как кнопка |
| [Значок](/ru/components/inline/icon/) | Значок Material Symbols внутри текста и список всех 3926 значков |
| [Клавиатурный ввод](/ru/components/inline/kbd/) | Клавиша или сочетание клавиш |

## Как выбрать

Эти элементы стоят внутри строки текста и не разрывают абзац. Бейдж помечает статус
или версию, кнопка-ссылка ведёт к следующему действию, значок поясняет смысл
картинкой, а клавиатурный ввод показывает клавишу или сочетание клавиш. Бейдж не
нажимается: для перехода на другую страницу возьмите кнопку-ссылку.
