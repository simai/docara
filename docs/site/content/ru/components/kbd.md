# Клавиатурный ввод

Клавиша выделяет кнопку или сочетание клавиатуры внутри инструкции и
отличает его от обычного текста и кода.

## Общий пример

:::example {label="Общий пример"}
```markdown
Нажмите :kbd[Esc], чтобы закрыть окно.
```
:::

## Сочетания

Записывайте каждую клавишу отдельно, а между ними ставьте обычный знак `+`.

:::example {label="Сочетание клавиш"}
```markdown
Откройте поиск сочетанием :kbd[⌘] + :kbd[K], затем нажмите :kbd[Enter].
```
:::

## Вызов

```markdown
:kbd[Ctrl] + :kbd[C]
```

Используйте подпись, которую читатель видит на клавиатуре. Для команды меню,
имени файла или фрагмента кода выбирайте обычный текст либо обратные кавычки.

## Правила записи

- В квадратных скобках — простой текст. HTML внутри не работает: знаки `<` и
  `>` выводятся как есть.
- Пустая клавиша `:kbd[]` останавливает сборку с ошибкой
  `CONTENT_COMPONENT_SLOT_REQUIRED`.
- Параметров у компонента нет. Запись вроде `:kbd[Esc]{size=1}` отклоняется с
  ошибкой `CONTENT_COMPONENT_PROP_UNKNOWN`.

Клавиша выводится HTML-элементом `kbd`, поэтому программы экранного доступа
распознают её как клавиатурный ввод.
