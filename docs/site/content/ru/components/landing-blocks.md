# Блоки лендинга

Из этих блоков собирают продуктовую страницу: [главная](/ru/) этого сайта
сделана из них, первого экрана и раскрывающихся вопросов. Блоки пишутся
обычным Markdown внутри `:::имя` и `:::`. Вид определяется содержимым, а
ширину, отступы и тему задаёт SIMAI Framework.

| Блок | Для чего |
| --- | --- |
| [`features`](#features-карточки-преимуществ) | Две–шесть карточек: значок или картинка, заголовок и короткий текст |
| [`showcase`](#showcase-показать-результат) | Заголовок, пояснение, действие и большая картинка результата |
| [`promo`](#promo-финальный-призыв) | Финальный блок страницы с одним действием |
| [`columns`](#columns-колонки) | Две–четыре колонки текста рядом |
| [`cta`](#cta-кнопка-действия) | Одна заметная кнопка-ссылка |

## Пример

:::example {label="Карточки преимуществ"}
```markdown
:::features
- :icon[description]{size=2 container=square variant=tonal scheme=primary} **Markdown.** Страницы пишутся обычным текстом.
- :icon[tune]{size=2 container=square variant=tonal scheme=primary} **JSON.** Настройки проверяются схемами.
- :icon[public]{size=2 container=square variant=tonal scheme=primary} **HTML.** Готовый сайт открывается без сервера.
:::
```
:::

## Разметка

- Блок начинается строкой `:::имя` без отступа и заканчивается строкой `:::`.
- Блоки не вкладываются друг в друга и в другие блоки Docara. Внутри
  `columns` можно писать обычный Markdown.
- Ссылки и картинки — только `https://` или пути внутри сайта.
- Нарушение правил останавливает сборку с понятным кодом, например
  `MARKDOWN_FEATURES_ITEM_COUNT_INVALID` или `MARKDOWN_CTA_LINK_REQUIRED`.
  Все коды с причинами и исправлениями — в справочнике
  [ошибок страниц](/ru/reference/errors/content/#features-logos-cta-showcase-promo-columns-surface).

Первый экран описан на странице [«Первый экран»](../hero/), раскрывающиеся
вопросы — на странице [«Раскрывающийся блок»](../details/). Как собрана
главная, рассказано на странице [«Как собрана главная страница»](/ru/landing/).

### Features: карточки преимуществ

Блок превращает маркированный список в сетку карточек. В списке от двух до
шести пунктов, в каждом — один абзац. Пункт может начинаться со значка
`:icon[...]` или картинки: они встают над текстом карточки. Жирный текст в
начале пункта становится заголовком карточки.

:::example {label="Карточки со значками"}
```markdown
:::features
- :icon[bolt]{size=2 container=square variant=tonal scheme=primary} **Быстро.** Сборка выдаёт готовые HTML, CSS и JavaScript.
- :icon[search]{size=2 container=square variant=tonal scheme=primary} **Поиск.** Индекс работает в браузере читателя без сервера.
- :icon[translate]{size=2 container=square variant=tonal scheme=primary} **Языки.** Каждый язык — своя папка с Markdown.
:::
```
:::

Значок, записанный не первым, остаётся обычным значком внутри текста. Вместо
значка можно поставить картинку: `- ![](../../assets/feature-layout.webp) **JSON.** Текст.`
Картинка в карточке декоративная, поэтому её alt можно оставить пустым.

:::example {label="Карточки с картинками"}
```markdown
:::features
- ![](../../assets/feature-content.webp) **Markdown.** Содержимое остаётся читаемым исходным текстом.
- ![](../../assets/feature-layout.webp) **JSON.** Настройки наследуются и проверяются схемами.
- ![](../../assets/feature-build.webp) **PHP.** Для сборки не нужен Node.js.
:::
```
:::

### Showcase: показать результат

Блок показывает результат крупно: заголовок второго уровня, один или два
абзаца описания, необязательная ссылка-действие и одна картинка последней
строкой. У картинки обязательно описание (alt), потому что она несёт смысл.
На широком экране текст стоит рядом с картинкой, на узком — над ней.

:::example {label="Показ результата"}
```markdown
:::showcase
## Посмотрите на результат до публикации

Docara собирает интерфейс документации из Markdown, JSON и проверенных
компонентов.

[Открыть быстрый старт](/ru/start/quick-start/)

![Страница документации в светлой и тёмной теме](../../assets/showcase.webp)
:::
```
:::

### Promo: финальный призыв

Блок закрывает страницу: заголовок второго уровня, один или два абзаца и
ровно одна ссылка-действие. Картинка последней строкой необязательна. Блок
выделен приглушённым фоном. На главной этого сайта promo стоит в самом конце
и ведёт в быстрый старт.

:::example {label="Финальный призыв"}
```markdown
:::promo
## Соберите первый сайт

Быстрый старт проведёт от пустого каталога до готовой страницы в браузере.

[Перейти к быстрому старту](/ru/start/quick-start/)
:::
```
:::

:::example {label="Призыв с картинкой"}
```markdown
:::promo
## Один источник для сайта и документации

Markdown и JSON превращаются в проверенный статический сайт.

[Как это устроено](/ru/start/component-model/)

![](../../assets/promo.webp)
:::
```
:::

### Columns: колонки

Блок ставит рядом от двух до четырёх частей текста. Части разделяются
отдельной строкой `---` с пустыми строками до и после. На узком экране
колонки встают друг под другом в том же порядке.

:::example {label="Три колонки"}
```markdown
:::columns
### Markdown

Содержимое остаётся читаемым исходным текстом.

---

### JSON

Настройки наследуются и проверяются схемами.

---

### PHP

Для сборки не нужен Node.js.
:::
```
:::

Внутри колонки можно писать обычный Markdown: абзацы, списки, ссылки. Пустая
колонка останавливает сборку.

### CTA: кнопка действия

Блок показывает одну ссылку как заметную кнопку. В нём ровно одна ссылка с
текстом.

:::example {label="Кнопка действия"}
```markdown
:::cta
[Открыть каталог компонентов](/ru/components/)
:::
```
:::

Если действий несколько, используйте [кнопки-ссылки](/ru/components/button/)
в абзаце или showcase со ссылками.

## Доступность

- Карточки `features` и колонки `columns` идут в исходном порядке: на
  телефоне они встают столбиком в том же порядке, в каком написаны.
- Картинка в `showcase` несёт смысл, поэтому описание у неё обязательно.
  Картинки в `features` и `promo` — украшение, их описание можно оставить
  пустым `![](…)`.
- Ссылки-действия в `showcase`, `promo` и `cta` — обычные ссылки: Tab и
  Enter. Пишите в них действие: «Перейти к быстрому старту».
- Заголовки блоков (`##` в `showcase` и `promo`, `###` в `columns`) входят в
  структуру страницы: держите их уровни по порядку.
