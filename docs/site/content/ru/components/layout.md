# Макет

Карточки, сетки, первый экран и другие блоки, из которых собирается страница или лендинг.

| Компонент | Для чего |
| --- | --- |
| [Карточка](/ru/components/layout/card/) | Короткий самостоятельный блок с заголовком |
| [Сетка](/ru/components/layout/grid/) | Несколько карточек в ряд, которые на телефоне встают в столбик |
| [Оформленная полоса](/ru/components/layout/surface/) | Оформленная полоса на всю ширину вокруг части страницы |
| [Первый экран](/ru/components/layout/hero/) | Начало лендинга: заголовок, описание, действия и картинка |
| [Фоновые эффекты](/ru/components/layout/effects/) | Анимация под текстом первого экрана вместо картинки |
| [Блоки лендинга](/ru/components/layout/landing-blocks/) | Карточки преимуществ, показ результата, колонки и призыв к действию |

## Как выбрать

Лендинг начинается с первого экрана: заголовка, описания, действий и картинки или
фонового эффекта. Ниже идут карточки в сетке, колонки и блоки лендинга. Оформленная
полоса выделяет часть страницы фоном на всю ширину. Все блоки макета на телефоне
перестраиваются в один столбец сами, отдельной вёрстки для узкого экрана не
нужно.
