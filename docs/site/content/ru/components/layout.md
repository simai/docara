# Макет

Карточки, сетки, первый экран и другие блоки, из которых собирается страница или лендинг.

| Компонент | Для чего |
| --- | --- |
| [Карточка](/ru/components/layout/card/) | Короткий самостоятельный блок с заголовком |
| [Сетка](/ru/components/layout/grid/) | Несколько карточек в ряд, которые на телефоне встают в столбик |
| [Колонки и ширина](/ru/components/layout/columns/) | Части страницы рядом с заданными долями и блок уже колонки страницы |
| [Оформленная полоса](/ru/components/layout/surface/) | Оформленная полоса на всю ширину вокруг части страницы |

## Как выбрать

Лендинг начинается с первого экрана: заголовка, описания, действий и картинки или
фонового эффекта. Ниже идут карточки в сетке, колонки и блоки лендинга. Оформленная
полоса выделяет часть страницы фоном на всю ширину. Все блоки макета на телефоне
перестраиваются в один столбец сами, отдельной вёрстки для узкого экрана не
нужно.

## Отступ под блоком

Под каждым блоком Docara оставляет небольшой отступ, а заголовок раздела
добавляет над собой свой, больший. Параметр `space` задаёт отступ под блоком
явно — шагом шкалы отступов SIMAI Framework от `0` до `8`, по умолчанию `1`.
Его принимает любой блок: первый экран, сетка, колонки, полоса, уведомление и
другие.

Если `space` написан, расстояние до следующего блока или заголовка ровно такое:
заголовок после такого блока своего отступа сверху не добавляет. Если не
написан, всё остаётся как раньше. Так расстояние решает одно место — блок
сверху.

```markdown
:::hero {layout=split padding=2xl space=6}
# Документация из файлов

Сайт собирается сам.
:::

## Почему удобно

::::grid {columns=3 space=6}
:::card
#### Быстро

Сборка одной командой.
:::
::::
```

На лендинге удобно держать один шаг для всех разделов, например `space=6`.
