# Колонки и ширина

Колонки ставят рядом несколько частей страницы: текст и код, вопросы и
справку, короткое описание и подробности. Блок ширины `:::container` делает
одну часть уже колонки страницы — например, призыв к действию по центру.

Оба блока смотрят на свою ширину, а не на ширину окна. Поэтому одна и та же
запись работает в колонке документации между меню и оглавлением, на лендинге
во всю ширину и внутри другого блока.

## Пример

:::example {label="Колонки 1:2"}
```markdown
:::columns {ratio=1/2 gap=4 align=start}
### Версия 1.10

Что изменилось в выпуске.

---

- Новая колонка «Статус»
- Запись открывается рядом со списком
- Быстрее на больших списках
:::
```
:::

## Разметка

```markdown
:::columns {ratio=2/1}
Первая колонка: любой Markdown.

---

Вторая колонка.
:::
```

- Колонки разделяет строка `---` с пустыми строками до и после неё.
- В блоке от двух до четырёх колонок. Внутри — любой Markdown, а также
  карточки, уведомления, шаги и раскрывающиеся блоки. Внешнему блоку нужно на
  одно двоеточие больше: `::::columns` вокруг `:::details`.
- Когда блоку не хватает ширины, колонки встают одна под другой в том же
  порядке.

## Варианты

### Доли

`ratio` — доли ширины слева направо: `2/1` — левая колонка вдвое шире правой,
`1/1/1` — три равные. Число долей равно числу колонок. Без параметра колонки
равные.

:::example {label="Текст и пометка 3:1"}
```markdown
:::columns {ratio=3/1 align=center}
Ширина панели записи по умолчанию.

---

**52 знака**
:::
```
:::

### Блоки внутри колонок

В колонку можно поставить [раскрывающиеся блоки](/ru/components/blocks/details/),
[карточку](/ru/components/layout/card/), [уведомление](/ru/components/blocks/alert/),
[иллюстрацию](/ru/components/images-and-files/figure/) или [шаги](/ru/components/blocks/steps/).
Тогда у внешнего блока на одно двоеточие больше.

:::example {label="Вопросы и справка рядом"}
```markdown
::::columns {ratio=2/1}
### Частые вопросы

:::details {layout=lines}
### Нужен ли Node.js на сервере?

Нет, только для сборки. Готовый сайт статический.
:::

:::details {layout=lines}
### Можно ли сделать лендинг?

Да, preset `landing` убирает меню документации.
:::

---

:::card
### Коротко

Docara 3, лицензия Apache 2.0.
:::
::::
```
:::

### Когда складываться

`fold` — с какой ширины блока колонки встают одна под другой: `sm` — уже
32rem, `md` — уже 44rem, `lg` — уже 60rem, `none` — никогда. Без параметра две
колонки складываются на `md`, три и четыре — на `lg`.

:::example {label="Три колонки, которые не складываются"}
```markdown
:::columns {ratio=1/1/1 fold=none gap=1}
**Markdown**

---

**JSON**

---

**HTML**
:::
```
:::

### Расстояние и выравнивание

`gap` — расстояние между колонками по шкале отступов SIMAI Framework, от `0`
до `8`, по умолчанию `2`. `align` — как колонки стоят по высоте: `start` — по
верху, `center` — по середине, `end` — по низу, `stretch` — во всю высоту ряда.

## Ширина блока

`:::container` делает блок уже колонки страницы. `width` — доля колонки:
`1/4`, `1/3`, `1/2`, `2/3`, `3/4` или `full`. `align` — где стоит блок:
`start`, `center` или `end`. По центру встают доли `1/3`, `1/2` и `2/3`.
Когда блоку не хватает ширины (уже 44rem), он занимает всю колонку.

:::example {label="Половина по центру"}
```markdown
:::container {width=1/2 align=center}
**Начните с одной команды.** Остальное Docara сделает сама.
:::
```
:::

:::example {label="Две трети от начала"}
```markdown
:::container {width=2/3}
Подпись к разделу или заметка, которая не должна идти на всю ширину.
:::
```
:::

Ширина в знаках (`width=44`, `width=64`) появится, когда SIMAI Framework
выпустит ступени ширины текста.

## Доступность

- Колонки и ширина отвечают только за расположение. Читатель и программы
  экранного доступа проходят колонки в исходном порядке, слева направо.
- Не меняйте порядок частей ради внешнего вида: на узком экране они встанут
  столбиком именно в этом порядке.
- Заголовок внутри колонки — обычный заголовок страницы. Держите уровни
  по порядку.

## Параметры

<!-- docara:component-parameters:start -->

### `:::columns`

| Параметр | Значения | По умолчанию | Что задаёт |
| --- | --- | --- | --- |
| `ratio` | `1/1`, `2/1`, `1/2`, `3/1`, `1/3`, `3/2`, `2/3`, `1/1/1`, `2/1/1`, `1/2/1`, `1/1/2`, `1/1/1/1` | — | Доли ширины колонок на широком экране, слева направо: `2/1` — левая вдвое шире правой. Число долей равно числу колонок. Без параметра колонки равные; на телефоне они встают одна под другой. |
| `gap` | `0`, `1`, `2`, `3`, `4`, `5`, `6`, `7`, `8` | `2` | Расстояние между колонками по шкале отступов SIMAI Framework, от `0` до `8`. |
| `fold` | `sm`, `md`, `lg`, `none` | — | Когда колонки встают одна под другой, по ширине самого блока: `sm` — уже 32rem, `md` — уже 44rem, `lg` — уже 60rem, `none` — никогда. Без параметра две колонки складываются на `md`, три и четыре — на `lg`. |
| `align` | `start`, `center`, `end`, `stretch` | — | Выравнивание колонок по высоте: `start` — по верху, `center` — по середине, `end` — по низу, `stretch` — растянуть на всю высоту ряда. |

### `:::container`

| Параметр | Значения | По умолчанию | Что задаёт |
| --- | --- | --- | --- |
| `width` (обязательный) | `1/4`, `1/3`, `1/2`, `2/3`, `3/4`, `full` | — | Ширина блока — доля колонки страницы: `1/4`, `1/3`, `1/2`, `2/3`, `3/4` или `full` на всю ширину. Уже 44rem блок занимает всю ширину. |
| `align` | `start`, `center`, `end` | `start` | Где стоит блок: `start` — у начала строки, `center` — по центру (для `1/3`, `1/2`, `2/3`), `end` — у конца строки. |
