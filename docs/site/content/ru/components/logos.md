# Логотипы и участники

Блок показывает компактный ряд продуктов, партнёров или участников. Элементы
могут быть обычным текстом, ссылками либо доступными изображениями.

## Общий пример

:::example {label="Общий пример"}
```markdown
:::logos
- SIMAI Framework
- Docara
- SIMAI Effects
:::
```
:::

## Ссылки

Каждый пункт может вести на отдельную безопасную страницу. Параметр
`tone=muted` уменьшает визуальный акцент, но не скрывает подписи.

:::example {label="Ссылки"}
```markdown
:::logos {tone=muted}
- [SIMAI](https://simai.io/)
- [GitHub](https://github.com/)
- [Документация](../)
:::
```
:::

## Изображения

:::example {label="Логотипы"}
```markdown
:::logos
- [![SIMAI](../../assets/simai.svg)](https://simai.io/)
- ![Docara](../../assets/docara-mark.svg)
:::
```
:::

## Вызов

```markdown
:::logos {tone=default}
- Первый участник
- Второй участник
:::
```

## Правила

| Что | Требование |
| --- | --- |
| Содержимое | Один плоский маркированный список, без вложенных списков и другого текста |
| Число пунктов | От двух до двенадцати |
| Пункт | Один короткий абзац: текст, ссылка или изображение |
| `tone` | `default` (по умолчанию) или `muted` |

На телефоне логотипы стоят в две колонки, на планшете — в три, на широком
экране — в шесть. Изображения загружаются по мере прокрутки.

У изображения должен быть замещающий текст с названием продукта или
участника. Не смешивайте в одном пункте несколько логотипов или длинное
описание. Ошибки этого блока описаны в разделе
[«Блоки лендинга»](/ru/reference/errors/content/#блоки-лендинга) справочника
ошибок.
