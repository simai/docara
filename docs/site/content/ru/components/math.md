# Математическая формула

Блок отделяет формулу TeX от обычного текста и добавляет доступную подпись.
Он подходит для коротких выражений и самостоятельных формул.

## Общий пример

:::example {label="Общий пример"}
```markdown
:::math {display=block label="Теорема Пифагора"}
a^2 + b^2 = c^2
:::
```
:::

## Отображение

`display=inline` предназначен для компактного выражения, а `display=block` —
для самостоятельной формулы. `label` объясняет смысл вспомогательным технологиям.

:::example {label="Строчная и блочная формулы"}
```markdown
:::math {display=inline label="Теорема Пифагора"}
a^2 + b^2 = c^2
:::

:::math {display=block label="Интеграл от нуля до бесконечности"}
\int_0^\infty e^{-x}\,dx = 1
:::
```
:::

## Вызов

```markdown
:::math {display=block label="Площадь круга"}
S = \pi r^2
:::
```

Пишите только формулу без ограждающих `$`. Подпись должна называть выражение,
а не повторять TeX посимвольно.
