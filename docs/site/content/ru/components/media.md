# Текст с изображением

Блок ставит рядом короткое объяснение и одно изображение. На широком экране
они стоят в две колонки, на телефоне — одна под другой в порядке чтения.

## Пример

:::example {label="Текст с изображением"}
```markdown
:::media
## Текст слева

Изображение дополняет объяснение и на узком экране переносится ниже.

![Схема: исходные файлы, компоненты и готовая страница](../../assets/media-flow.webp)
:::
```
:::

## Разметка

```markdown
:::media
## Понятный заголовок

Короткое объяснение связи текста и изображения.

![Описание изображения](../../assets/scheme.webp)
:::
```

- Внутри — текст и одно изображение отдельным абзацем. Без изображения или
  без текста сборка останавливается с ошибкой
  `MARKDOWN_MEDIA_CONTENT_REQUIRED`.
- Если изображений несколько, в колонку попадает первое, а остальные остаются
  в тексте. Для нескольких картинок выбирайте [иллюстрации](../figure/).

## Варианты

### Сторона

`side` выбирает, с какой стороны изображение на широком экране. Порядок в
исходном Markdown не меняется.

:::example {label="Изображение слева"}
```markdown
:::media {side=left}
## Изображение слева

Зеркальный вариант использует тот же порядок исходного Markdown.

![Компоненты страницы вокруг знака Docara](../../assets/media-components.webp)
:::
```
:::

### Пропорции

`ratio` закрепляет соотношение сторон изображения, чтобы макет не прыгал во
время загрузки.

:::example {label="Квадратное изображение"}
```markdown
:::media {ratio=1/1}
## Квадрат

Подходит для знаков и портретов.

![Компоненты страницы вокруг знака Docara](../../assets/media-components.webp)
:::
```
:::

## Доступность

- Порядок чтения не зависит от стороны: сначала текст, потом изображение.
- Описание изображения должно объяснять смысл: «Страница Docara на широком и
  узком экране», а не «скриншот».
- Изображение загружается по мере прокрутки и не замедляет открытие страницы.

## Параметры

<!-- docara:component-parameters:start -->

| Параметр | Значения | По умолчанию | Что задаёт |
| --- | --- | --- | --- |
| `side` | `left`, `right` | `right` | С какой стороны изображение. |
| `ratio` | `1/1`, `4/3`, `3/2`, `16/9`, `21/9` | `16/9` | Соотношение сторон изображения. |

<!-- docara:component-parameters:end -->
