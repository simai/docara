# Текст с изображением

Блок объединяет короткое объяснение и одно изображение. На узком экране обе
части складываются вертикально, сохраняя порядок чтения.

## Общий пример

:::example {label="Общий пример"}
```markdown
:::media {side=right ratio=16/9}
## Текст слева

Изображение дополняет объяснение и на узком экране переносится ниже.

![Схема Docara](../../assets/docara-flow.png)
:::
```
:::

## Положение

`side=right` показывает изображение справа на широком экране, а `side=left` —
слева. На телефоне компонент использует одну колонку.

:::example {label="Изображение слева"}
```markdown
:::media {side=left ratio=16/9}
## Изображение слева

Зеркальный вариант использует тот же порядок исходного Markdown.

![Схема Docara](../../assets/docara-flow.png)
:::
```
:::

## Пропорции

`ratio` принимает `1/1`, `4/3`, `3/2`, `16/9` или `21/9`. Выбирайте значение по
смыслу изображения, чтобы макет не прыгал во время загрузки.

## Вызов

```markdown
:::media {side=right ratio=4/3}
## Понятный заголовок

Короткое объяснение связи текста и изображения.

![Интерфейс Docara](../../assets/docara-screen.png)
:::
```

## Параметры

| Параметр | Значения | По умолчанию |
| --- | --- | --- |
| `side` | `left` или `right` — с какой стороны изображение на широком экране | `right` |
| `ratio` | `1/1`, `4/3`, `3/2`, `16/9` или `21/9` | `16/9` |

Блоку нужно одно изображение отдельным абзацем и текст рядом с ним. Если
изображений несколько, в отдельную колонку попадает первое, а остальные
остаются в тексте. Без изображения или без текста сборка останавливается с
ошибкой `MARKDOWN_MEDIA_CONTENT_REQUIRED`. Изображение загружается по мере
прокрутки.

Пишите осмысленный замещающий текст. Не используйте блок для галереи или
длинной статьи.
