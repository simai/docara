# SIMAI Framework

Компоненты SIMAI Framework, которые можно вставить прямо в Markdown.

| Компонент | Для чего |
| --- | --- |
| [Компоненты SIMAI Framework ui.*](/ru/components/simai-framework/smart-ui/) | Кнопка `ui.button`, уведомление `ui.alert` и другие элементы Framework с проверкой параметров |

## Когда использовать

Компоненты SIMAI Framework нужны, когда сайт Docara работает поверх дизайн-системы
SIMAI и должен выглядеть так же, как остальные продукты. Docara проверяет параметры
каждого компонента при сборке и сообщает об ошибке до публикации. Если подходящий
блок Docara уже есть, например уведомление или кнопка-ссылка, начните с него:
он проще и не зависит от версии Framework.
