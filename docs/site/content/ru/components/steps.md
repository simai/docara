# Шаги

Блок показывает короткую последовательность действий. Временная линия
подходит для процесса с текущим состоянием, обычный список — для нейтральной
инструкции.

## Общий пример

:::example {label="Общий пример"}
```markdown
:::steps {view=timeline current=2}
1. Создайте проект.
2. Добавьте страницы.
3. Опубликуйте сайт.
:::
```
:::

## Параметры и варианты

`view=timeline` отмечает завершённые, текущий и будущие шаги. Параметр
`current` принимает номер текущего пункта, начиная с `1`.
Маркер и текст размещаются в отдельных колонках, поэтому увеличение размера
чтения не должно приводить к их наложению.
Маркеры соединены одной вертикальной линией, а завершённый, текущий и будущий
шаги различаются состоянием. Заголовок внутри шага лучше оформлять жирным
текстом, а не крупным heading.

:::steps {view=timeline current=2}
1. Создайте проект.
2. Добавьте страницы.
3. Опубликуйте сайт.
:::

`view=list` оставляет компактный нумерованный список без статусных маркеров.

:::steps {view=list}
1. Подготовьте Markdown.
2. Проверьте JSON.
3. Соберите статический сайт.
:::

## Вызов

```markdown
:::steps {view=timeline current=3}
1. Структура готова.
2. Страницы добавлены.
3. Проверьте результат.
:::
```

Внутри блока должен быть ровно один нумерованный список. Используйте короткие
действия в одном грамматическом стиле и не вкладывайте другие директивы.

Блок имеет capability `content.embeddable`, поэтому его можно помещать внутрь
`Surface`, когда последовательность должна визуально отделяться от основного
потока страницы.
