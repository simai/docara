# Дерево файлов

Дерево показывает структуру каталогов и файлов с явной вложенностью. Выбирайте
его, когда читателю нужно понять, где лежит файл и что рядом с ним.

## Пример

:::example {label="Дерево файлов"}
```markdown
:::tree
- content
  - ru
    - index.md
    - section.json
  - assets
    - logo.svg
- docara.json
:::
```
:::

## Разметка

```markdown
:::tree
- папка
  - вложенный файл
- файл
:::
```

- Внутри блока — один ненумерованный список Markdown. Вложенность задаётся
  отступом в два пробела.
- Пункт со вложенным списком становится папкой, пункт без него — файлом.
  В подписи можно использовать код: `` `index.md` ``.

Блок построен на дереве SIMAI Framework (`sf-tree`).

## Варианты

### Сворачивание папок

По умолчанию папки можно сворачивать. `interactive=false` делает дерево
статичным: это обычный вложенный список, все папки раскрыты, нажимать
нечего. Перед каждым именем стоит значок папки или файла, а вложенный
уровень начинается ровно под именем родителя.

:::example {label="Статичное дерево"}
```markdown
:::tree {interactive=false}
- content
  - index.md
- docara.json
:::
```
:::

## Состояния

### Раскрытые папки

При открытии страницы все папки раскрыты, поэтому структура видна целиком и
без скриптов. Свёрнутая папка показывает закрытый значок.

## Доступность

- Дерево — `tree`: Tab переводит в него фокус, стрелки вверх и вниз
  переходят между строками, стрелка вправо раскрывает папку, влево —
  сворачивает, Home и End переходят к первой и последней строке.
- Папку можно свернуть и щелчком по её значку.
- Статичное дерево — вложенный список: фокус на него не переходит,
  программа экранного доступа читает уровни как уровни списка.
- Дерево объясняет структуру. Не используйте его как меню навигации: для
  ссылок по сайту есть боковое меню.

## Параметры

<!-- docara:component-parameters:start -->

| Параметр | Значения | По умолчанию | Что задаёт |
| --- | --- | --- | --- |
| `interactive` | `true`, `false` | `true` | Папки можно сворачивать мышью и с клавиатуры. При `false` дерево всегда раскрыто. |
