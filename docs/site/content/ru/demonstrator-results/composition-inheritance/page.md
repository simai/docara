# Отмена платежа

Платёж в статусе `pending` можно отменить, пока покупатель его не оплатил.
Оплаченный платёж не отменяется: для него создайте возврат.

## Запрос

```bash {title="Запрос"}
curl -X POST https://api.acme-pay.example/v1/payments/pay_2Hk81/cancel \
  -u "$ACME_TEST_KEY:"
```

## Ответ

Платёж переходит в статус `canceled`, а страница оплаты перестаёт
открываться.

## Ограничения

Отменить платёж можно в течение 24 часов после создания. Позже он отменяется
автоматически.
