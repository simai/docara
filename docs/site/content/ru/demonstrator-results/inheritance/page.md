# Объект Payment

Платёж хранит сумму, валюту, статус и историю изменений. Все поля приходят в
ответе на создание платежа и в уведомлениях.

| Поле | Тип | Пример | Описание |
|---|---|---|---|
| `id` | строка | `pay_2Hk81` | Идентификатор платежа |
| `amount` | строка | `1500.00` | Сумма с двумя знаками после точки |
| `currency` | строка | `RUB` | Валюта по ISO 4217 |
| `status` | строка | `succeeded` | `pending`, `succeeded` или `canceled` |
| `created_at` | дата и время | `2026-11-02T10:15:00Z` | Время создания в UTC |
| `confirmation_url` | строка | `https://pay.acme-pay.example/c/2Hk81` | Страница оплаты для покупателя |
