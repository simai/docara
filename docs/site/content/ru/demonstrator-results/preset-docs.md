# Быстрый старт

За десять минут вы примете первый тестовый платёж: получите ключ, создадите
платёж и проверите уведомление.

## 1. Получите тестовый ключ

Откройте личный кабинет, раздел «Ключи», и нажмите «Создать тестовый ключ».
Тестовый ключ начинается с `test_`.

## 2. Создайте платёж

```bash {title="Запрос"}
curl https://api.acme-pay.example/v1/payments \
  -u "$ACME_TEST_KEY:" \
  -d amount=100.00 \
  -d currency=RUB
```

## 3. Оплатите тестовой картой

Откройте `confirmation_url` из ответа и введите карту `4111 1111 1111 1111`
с любым сроком действия в будущем.
