# Платежи для интернет-магазина за один день

Подключите оплату картами и через СБП одним API. Тестовый режим доступен сразу
после регистрации.

[Начать бесплатно](/ru/demonstrator-results/preset-docs/)
:::

:::features
- **Один запрос.** Платёж создаётся одним вызовом API, страницу оплаты Acme Pay показывает сама.
- **Возвраты.** Полные и частичные возвраты из кабинета или через API.
- **Уведомления.** Магазин узнаёт об оплате сразу, без опроса API.
:::
