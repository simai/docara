# Уведомления о платежах

Acme Pay отправляет уведомление на ваш адрес каждый раз, когда меняется статус
платежа или возврата. Так магазин узнаёт об оплате без опроса API.

## Подключение

Укажите адрес для уведомлений в личном кабинете. Адрес должен работать по
HTTPS и отвечать кодом `200` за пять секунд.

## Формат уведомления

```json {title="Тело запроса"}
{
  "event": "payment.succeeded",
  "payment_id": "pay_2Hk81",
  "amount": "1500.00"
}
```

## Повторная отправка

Если ваш сервер не ответил, Acme Pay повторит отправку через 1, 5 и 30 минут,
а затем раз в час в течение суток.
