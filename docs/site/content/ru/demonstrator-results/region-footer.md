# Коды ошибок API

Если запрос не выполнен, API отвечает кодом HTTP и объектом `error` с
машинным кодом и пояснением.

| Код | HTTP | Что сделать |
|---|---|---|
| `invalid_amount` | 400 | Передайте сумму строкой с двумя знаками после точки |
| `invalid_key` | 401 | Проверьте ключ и режим: тестовый или боевой |
| `payment_not_found` | 404 | Проверьте идентификатор платежа |
| `rate_limited` | 429 | Повторите запрос через время из заголовка `Retry-After` |
