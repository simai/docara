# Приём первого платежа

Создайте платёж, передайте покупателя на страницу оплаты и дождитесь
уведомления о результате. Для проверки хватит тестового ключа: деньги не
списываются.

## 1. Создайте платёж

```bash {title="Запрос"}
curl https://api.acme-pay.example/v1/payments \
  -u "$ACME_TEST_KEY:" \
  -d amount=1500.00 \
  -d currency=RUB \
  -d return_url=https://shop.example/thanks
```

В ответе придёт адрес страницы оплаты `confirmation_url`. Передайте его
покупателю.

## 2. Дождитесь результата

| Статус | Что значит |
|---|---|
| `pending` | Покупатель ещё не оплатил |
| `succeeded` | Деньги получены |
| `canceled` | Покупатель отказался или время вышло |

:::alert {type=info}
#### Не опрашивайте API

Статус приходит на ваш адрес уведомлений.
:::
