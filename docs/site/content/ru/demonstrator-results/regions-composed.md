# Возврат платежа

Вернуть деньги можно полностью или частично в течение 180 дней после оплаты.
Возврат создаётся отдельным запросом и получает свой статус.

## Полный возврат

Передайте идентификатор платежа. Сумма возврата совпадёт с суммой платежа.

```bash {title="Запрос"}
curl https://api.acme-pay.example/v1/refunds \
  -u "$ACME_TEST_KEY:" \
  -d payment_id=pay_2Hk81
```

## Частичный возврат

Добавьте сумму `amount`. Несколько частичных возвратов не могут превысить
сумму платежа.

## Статусы возврата

| Статус | Что значит |
|---|---|
| `pending` | Банк ещё обрабатывает возврат |
| `succeeded` | Деньги отправлены покупателю |
| `canceled` | Банк отклонил возврат |
