# Условия использования API

Эти условия действуют для всех магазинов, которые принимают платежи через
Acme Pay. Читайте их целиком: страница без меню и оглавления отдаёт тексту
всю ширину.

## 1. Ключи доступа

Магазин хранит ключи в секрете и не передаёт их в браузер покупателя. Если
ключ мог попасть к посторонним, его нужно отозвать в личном кабинете в тот же
день.

## 2. Данные покупателей

Номера карт не проходят через сервер магазина: их вводят на странице оплаты
Acme Pay. Магазин получает только последние четыре цифры и срок действия.

## 3. Ограничения

Не больше 100 запросов в секунду с одного ключа. При превышении API отвечает
кодом `429`.
