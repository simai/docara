# Тестовый режим

В тестовом режиме API работает так же, как в боевом, но деньги не
списываются, а уведомления приходят только на тестовый адрес.

:::ui.alert
{"type":"warning","variant":"outlined","title":"Деньги не списываются","supporting-text":"Платежи с тестовым ключом не доходят до банка. Перед запуском замените ключ на боевой.","closable":false,"aria-label":"Тестовый режим: деньги не списываются"}
:::

## Как переключиться на боевой режим

Создайте боевой ключ в личном кабинете и замените им тестовый в настройках
магазина.
