# Примеры для разработчиков

Выберите задачу, проверьте настоящий результат и скопируйте минимальные
исходные файлы. Каждый пример показывает отдельную публичную страницу,
собранную тем же PageBuilder, что и остальная документация.

[Полезные сценарии Framework и проекта](/ru/examples/extensions/) показывают
принятые элементы форм, конструктор установки, конфигуратор продукта и подвал.
Всё работает без серверной части.

## Сборка страницы из шаблона

:::card
### Страница из Composition Recipe

Один шаблон страницы получает содержимое из файлов, а настройка выбирает
компактную или расширенную шапку до создания HTML.

[Компактная шапка](/ru/examples/composition-recipe-compact/) ·
[Расширенная шапка](/ru/examples/composition-recipe-expanded/)
:::

## Области макета

:::columns
### Явная композиция областей

Шапка (`header`), боковое меню (`sidebar`) и правая колонка (`outline`)
получают зарегистрированные секции, а основная область — текст из Markdown.

[Открыть пример](/ru/examples/regions-composed/)

---

### Брендированная шапка

Фирменный Smart-компонент бренда и отдельное действие собираются как две
секции одной области.

[Открыть пример](/ru/examples/region-header/)

---

### Боковое меню с дополнительным блоком

Меню остаётся Smart-компонентом, а рядом появляется короткая безопасная
подсказка.

[Открыть пример](/ru/examples/region-sidebar/)

---

### Правая колонка с контекстом страницы

Правая область объединяет автоматически построенное оглавление и
информационный Smart-компонент.

[Открыть пример](/ru/examples/region-aside/)
:::

:::columns
### Подвал из безопасных блоков

Нижняя область (`footer`) включается явно и получает текст и локальную
ссылку без произвольного HTML.

[Открыть пример](/ru/examples/region-footer/)

---

### Отключение областей

Боковое меню и правая колонка отключаются без пустых контейнеров и лишней
мобильной навигации.

[Открыть пример](/ru/examples/regions-disabled/)
:::

## Наследование настроек

:::columns
### Раздел и страница

Раздел задаёт общие правила чтения, а страница переопределяет только ширину
макета.

[Открыть пример](/ru/examples/inheritance/)

---

### Композиция: сайт → раздел → страница

Сайт задаёт бренд и тему, раздел заменяет боковое меню и отключает правую
колонку, а страница сбрасывает настройку правой колонки и включает подвал.

[Открыть пример](/ru/examples/composition-inheritance/)
:::

## Виды страниц

:::columns
### Документация (`docs`)

Оболочка для последовательного чтения с меню, оглавлением и переходами между
страницами.

[Открыть пример](/ru/examples/preset-docs/)

---

### Лендинг (`landing`)

Сфокусированная страница без меню документации, собранная тем же
генератором.

[Открыть пример](/ru/examples/preset-landing/)
:::
