# Примеры для разработчиков

Каждый пример решает одну задачу. В нём настоящая собранная страница, которую
можно открыть на компьютере, планшете и телефоне, и файлы, из которых она
собрана. Демо-страницы показывают документацию вымышленного платёжного
сервиса Acme Pay.
