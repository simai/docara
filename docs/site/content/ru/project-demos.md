# Полезные компоненты проекта

Эти примеры лежат в каталоге `smart/` самого сайта и подключаются без изменения движка Docara. Страница открывается из раздела [Примеры](/ru/examples/extensions/) и не показывается в меню.

## Команда установки

Выберите операционную систему, способ установки, пакет, версию и опции. Компонент только формирует и копирует команду. Он ничего не скачивает и не запускает.

:::project.install-builder
{"title":"Соберите команду установки","package":"simai/docara","version":"^3.0"}
:::

## Конфигуратор продукта

Список меняет базовый тариф, флажки добавляют опции, итог пересчитывается в браузере. Демо не отправляет данные и не создаёт заказ.

:::project.product-configurator

:::
