# Ошибки поставки SIMAI Framework

Docara поставляет SIMAI Framework внутри своего пакета: стили, скрипты,
значки, шрифты и описания компонентов. Файл проекта
`simai-framework.lock.json` (поле `framework_lock` в `docara.json`) называет
точную версию этой поставки. Перед сборкой Docara сверяет каждый файл
Framework с закреплёнными хешами — поэтому сайт не зависит от внешних
серверов и не меняется сам по себе. Как устроен файл, описано на странице
[«Файл закрепления Framework»](/ru/reference/framework-lock/).

## Что делать в большинстве случаев

Почти все коды на этой странице означают одно из двух: файл закрепления не
совпадает с поставкой в пакете или файлы пакета повреждены.

1. Не правьте `simai-framework.lock.json` вручную.
2. Если вы недавно обновили Docara, замените файл закрепления проекта
   поставляемым:

   ```bash
   cp vendor/simai/docara/stubs/portable/simai-framework.lock.json simai-framework.lock.json
   ```

3. Восстановите файлы пакета из `composer.lock`: удалите папку
   `vendor/simai/docara` и выполните `composer install`.
4. Выполните полную сборку. Если ошибка осталась, сообщите о ней по
   инструкции со страницы [«Внутренние ошибки»](/ru/reference/errors/internal/#что-делать).

## Файл закрепления

| Код | Причина и что сделать |
| --- | --- |
| `FRAMEWORK_LOCK_MISSING`, `FRAMEWORK_LOCK_PATH_INVALID` | Файла из поля `framework_lock` нет. **Что сделать:** Скопируйте поставляемый файл, как показано выше, и проверьте путь в `docara.json`. |
| `FRAMEWORK_LOCK_JSON_INVALID` | Файл закрепления — не корректный JSON. **Что сделать:** Верните файл из истории проекта или замените поставляемым. |
| `FRAMEWORK_LOCK_SCHEMA_INVALID`, `FRAMEWORK_LOCK_INVALID`, `FRAMEWORK_LOCK_IDENTITY_INVALID` | В файле не хватает полей или версии в нём не согласованы между собой. **Что сделать:** Замените файл поставляемым. |
| `FRAMEWORK_MOVING_REFERENCE_FORBIDDEN`, `FRAMEWORK_ASSET_MOVING_REFERENCE_FORBIDDEN` | Версия указана подвижной ссылкой — `main`, `master`, `latest`, — содержимое которой меняется со временем. **Что сделать:** Укажите точную версию вида `v1.2.3` или замените файл поставляемым. |
| `FRAMEWORK_RUNTIME_RELEASE_REFERENCE_INVALID`, `FRAMEWORK_ASSET_COMMIT_REQUIRED` | Версия записана не в виде `v1.2.3` или адрес файла не содержит точный коммит. **Что сделать:** Замените файл поставляемым. |
| `FRAMEWORK_MANIFEST_NOT_LOCKED`, `FRAMEWORK_MANIFEST_UPSTREAM_REVISION_MISMATCH`, `FRAMEWORK_RUNTIME_PROJECTION_MISMATCH` | Файл закрепления называет другую версию Framework, чем поставляет установленная Docara, — обычно после обновления Docara. **Что сделать:** Замените файл поставляемым. |
| `FRAMEWORK_LOCK_CHANGED_DURING_BUILD` | Файл закрепления изменился, пока шла сборка. **Что сделать:** Дождитесь окончания правки и повторите сборку. |
| `FRAMEWORK_RUNTIME_MISSING` | В проекте нет ни одной страницы. **Что сделать:** Добавьте страницу в папку языка, например `content/ru/index.md`. |
| `FRAMEWORK_ASSET_PLAN_NOT_STABLE` | После вывода страницы набор нужных ей файлов Framework изменился. **Что сделать:** Пересоберите сайт; если ошибка повторяется, сообщите о ней. |

## Вызов компонента

| Код | Причина и что сделать |
| --- | --- |
| `FRAMEWORK_PRESET_UNKNOWN` | У компонента SIMAI Framework нет пресета с таким именем. **Что сделать:** Возьмите имя из `docara inspect smart <компонент> --json` или уберите `preset`. |
| `FRAMEWORK_PRESET_INVALID` | `preset` записан не строкой. **Что сделать:** Пишите `"preset": "имя"`. |

## Предупреждения о загрузке

Обычно Docara заранее знает, какие стили и скрипты Framework нужны странице, и
подключает только их. Эти предупреждения сообщают, что часть кода загрузится
по необходимости уже в браузере. Сборка не останавливается, сайт работает.

| Код | Что означает |
| --- | --- |
| `FRAMEWORK_COMPONENT_DYNAMIC_FALLBACK`, `FRAMEWORK_SMART_DYNAMIC_FALLBACK`, `FRAMEWORK_RELATION_DYNAMIC_FALLBACK` | Компонент или его зависимость загрузится в браузере по требованию. **Что сделать:** Ничего, если страница работает. |
| `FRAMEWORK_SHELL_PRELOAD_METADATA_MISSING` | В закреплённой версии нет списка файлов для предварительной загрузки. **Что сделать:** Ничего; после обновления Docara и файла закрепления предупреждение уйдёт. |
