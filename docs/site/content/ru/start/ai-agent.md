# Работа с ИИ-агентом

Навык Docara учит ИИ-агента вести сайт документации: создать проект, написать
страницы, подключить компоненты, собрать и проверить сайт. Агент работает в
вашей папке с проектом, а вы даёте задачи обычными словами. Навык открытый,
лицензия Apache 2.0, других инструментов кроме самой Docara ему не нужно.

## Установка

Навык — это папка `skills/docara` в репозитории
[simai/ai-skill-docara](https://github.com/simai/ai-skill-docara). Скопируйте её
в папку навыков вашего агента:

```bash
git clone https://github.com/simai/ai-skill-docara.git
# Claude Code
cp -R ai-skill-docara/skills/docara ~/.claude/skills/docara
# Codex
cp -R ai-skill-docara/skills/docara ~/.codex/skills/docara
```

Навык подходит и другим агентам, которые поддерживают формат
[Agent Skills](https://agentskills.io/specification): путь к папке навыков
смотрите в документации агента. Для сборки нужны те же
[PHP, Composer и Node.js](/ru/start/templates/), что и без агента.

## Что можно поручить

Агент сам выбирает навык, когда в проекте есть `docara.json` или вы упоминаете
Docara. Примеры задач:

- «Создай сайт документации для моей библиотеки на английском и русском».
- «Перенеси документацию из папки `docs/` в Docara и настрой меню».
- «Добавь страницу про установку с вкладками для каждой системы».
- «Обнови Docara до последней версии и проверь, что сайт собирается».
- «Сборка падает с ошибкой: разберись и исправь».

Навык опирается на версию Docara, установленную в проекте: он читает
`docara capabilities --json` и не предполагает команд, которых в этой версии нет.
Закончив работу, агент перечисляет, что изменил и какие проверки запустил.

## Публикация

Агент собирает сайт, запускает `verify-static` и показывает результат на
локальном адресе. Готовый сайт — обычная папка `build_production/`, её можно
выложить [на любой статический хостинг](/ru/build/publish/). Навык не выкладывает сайт
на живой сервер сам: доступы, резервная копия и разрешение на выкладку остаются
за вами.

## Файл AGENTS.md

`init` кладёт в новый проект файл `AGENTS.md`: стандарт страниц и команды
проверки для любого агента, даже без навыка. Навык дополняет его тем, чего там
нет: настройками, компонентами, обновлением и разбором ошибок.
