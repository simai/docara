# Заготовки и окружение

Команда `init` из [быстрого старта](/ru/start/quick-start/) создаёт проект из
заготовки. Здесь описано, какую заготовку выбрать, что появится в каталоге и
что должно быть в окружении сборки.

## Выбор заготовки

`init` принимает два основных параметра: `--template` (`-t`) выбирает
заготовку, а `--lang` (`-l`) — язык её содержимого. По умолчанию используется
`--template=minimal --lang=en`: небольшой рабочий сайт на английском. Заготовку
выбирают при первом `init`
([шаг 1 быстрого старта](/ru/start/quick-start/#1-создайте-проект)): в уже созданном проекте `init`
откажется работать.

```bash
# Небольшой сайт на английском (по умолчанию)
php vendor/bin/docara init .

# Тот же сайт на русском
php vendor/bin/docara init . --lang=ru

# Каталог компонентов, лендинг, вложенные руководства и Smart-примеры
php vendor/bin/docara init . --template=showcase --lang=ru

# Сайт набора компонентов SIMAI Framework с id «view»
php vendor/bin/docara init . --template=set --set=view --lang=ru
```

| Заготовка | Содержимое | Языки |
| --- | --- | --- |
| `minimal` | главная страница, страница о написании страниц (Markdown, код, таблица, `:::example`) и страница компонентов (alert, button, JSON-компонент `:::ui.button`) | `en`, `ru` |
| `showcase` | каталог компонентов, лендинг, вложенные руководства и проектные Smart-примеры | `ru` |
| `set` | сайт набора компонентов SIMAI Framework: обзор, подключение, компоненты, демо и изменения | `en`, `ru` |

Заготовка `showcase` написана только на русском. Сочетание
`--template=showcase --lang=en` завершается понятной ошибкой и ничего не
записывает.

## Сайт набора компонентов

Заготовка `set` — документация набора компонентов SIMAI Framework. В ней
пять разделов, которые есть у сайта любого набора, в таком порядке в меню:

| Раздел | Страница | Что заменить своим |
| --- | --- | --- |
| Обзор | `index.md` | таблицу компонентов, лицензию |
| Подключение | `connection.md` | таблицу выпусков; строка подключения уже с id набора |
| Компоненты | `components/` | по странице на компонент вместо образца `first-component.md` |
| Демо | `demos/` | страницы с экранами из компонентов |
| Изменения | `changes.md` | раздел на каждую версию набора |

Параметр `--set` — id набора из его `set.json`, например `view`. Заготовка
подставляет его в строку подключения `data-sf-sets`, в настройку
`SF_BOOT_CONFIG` и в заголовки. Без `--set` пишется `my-set`; id из
заглавных букв или с пробелами `init` не примет и ничего не запишет. Вместо
четырёх каталогов с типами страниц в `docara.authoring.json` заданы типы
этих разделов: обзор — лендинг, компоненты и изменения — справочник,
подключение и демо — статьи.

Строку о выпуске набора внизу каждой страницы добавляет блок
`shell.set-passport` в области `footer`, когда пакет набора закреплён в
`simai-framework.lock.json`; см. [«Строка набора компонентов в подвале»](/ru/settings/layout-and-regions/#строка-набора-компонентов-в-подвале).

## Окружение сборки

Docara содержит закреплённую поставку SIMAI Framework вместе со средой
выполнения Composition Recipe. Отдельная копия Framework и переменные
окружения для неё не нужны.

Node.js должен быть доступен командой `node`. Если он установлен в другом
месте, задайте `export DOCARA_NODE_BINARY=/path/to/node` в окружении сборки,
включая автоматические проверки и обновление Docara.

Проверить установку без сборки можно двумя командами: `capabilities` сообщает
версию и возможности установленной Docara, `doctor` — состояние контрактов
проекта.

```bash
php vendor/bin/docara capabilities --json
php vendor/bin/docara doctor --json
```

## Обновление

Docara обновляется одной командой `php vendor/bin/docara upgrade`, а
возвращается к прежней проверенной версии командой
`php vendor/bin/docara upgrade --rollback=latest`. Как это работает и что
проверяется, описано в разделе [«Обновление Docara»](/ru/build/update/).

## Какие файлы создаёт заготовка

Заготовка `minimal` с `--lang=ru` создаёт такие файлы:

```text
docara.json
docara.authoring.json
AGENTS.md
composer.json
composer.lock
vendor/
redirects.json
simai-framework.lock.json
assets/
contracts/
.docara/
  engine/
content/
  ru/
    section.json
    lang.json
    index.md
    index.page.json
    writing.md
    writing.page.json
    components.md
    components.page.json
    getting-started/
    how-to/
    reference/
    explanation/
```

С `--lang=en` содержимое лежит в `content/en/`. Сайт одноязычный, маршруты
без языкового префикса: `/`, `/writing/`, `/components/`.

Четыре каталога — каркас документации по типам страниц: урок, инструкция,
справочник и объяснение. В каждом лежит короткий пример страницы своего типа:
замените его своим текстом. `docara.authoring.json` включает проверку типов
страниц, а `AGENTS.md` пересказывает тот же стандарт для ИИ-помощников. Как
это работает, описано в [Профилях страниц](/ru/authoring/page-profiles/).
