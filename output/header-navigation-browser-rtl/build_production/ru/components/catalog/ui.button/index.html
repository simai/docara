Кнопка

ui.button · Smart-компонент SIMAI Framework

Выводит визуальный элемент действия; переносимая Docara не привязывает данные, не выполняет переход и не запускает действие.

Пример

Вызов

:::ui.button
{"text":"Демонстрационная кнопка","size":"1","type":"default","scheme":"primary","loading":false,"disabled":true,"native-type":"button","aria-label":"Демонстрационная кнопка без действия"}

:::

Параметры

ИмяТипОбязателенПо умолчаниюЗначенияПравилаНазначение
Доступное имяaria-labelstringНет"Save"
  • min_length: 1
  • max_length: 120
  • pattern: "\\S"
Называет кнопку для вспомогательных технологий.
ОтключенаdisabledbooleanНетfalse—Показывает недоступное для взаимодействия состояние.
ЗагрузкаloadingbooleanНетfalse—Показывает ожидание завершения действия; требует disabled=true.
Нативный типnative-typeenumНет"button"Кнопка — button, Отправка формы — submit, Сброс формы — reset—Задаёт стандартное поведение HTML-кнопки.
ПресетpresetenumНет—Ссылка основная — link, Ссылка на поверхности — link_on_surface, Обычная на поверхности — on_surface, Контурная основная — outline, Контурная на поверхности — outline_on_surface, Основная — primary, Вторичная тональная — secondary, Тональная на поверхности — tonal_on_surface—Применяет точный набор параметров манифеста до явно заданных значений.
СкруглениеradiusenumНет—По умолчанию SIMAI Framework — , Стандартное — default, Без скругления — square, Полностью скруглённая — rounded—Задаёт форму углов кнопки.
Цветовая схемаschemeenumНет"primary"Основная — primary, Вторичная — secondary, На поверхности — on-surface—Выбирает семантическую цветовую схему.
РазмерsizeenumНет"1"Очень маленькая · 1/3 — 1/3, Маленькая · 1/2 — 1/2, Обычная · 1 — 1, Большая · 2 — 2, Очень большая · 3 — 3—Задаёт размер кнопки по шкале SIMAI Framework.
ТекстtextstringНет"Save"
  • min_length: 1
  • max_length: 120
  • pattern: "\\S"
  • mirrors: aria-label
Задаёт видимую подпись кнопки.
ТипtypeenumНет"default"Заливка — default, Тональная — tonal, Контурная — outline, Ссылка — link—Выбирает визуальный тип кнопки.

Связи параметров

  • Допустимые сочетания allowed_combinations
    {"keys":["type","scheme"],"values":[["default","primary"],["default","on-surface"],["tonal","secondary"],["tonal","on-surface"],["outline","primary"],["outline","on-surface"],["link","primary"],["link","on-surface"]]}
  • requires
    если {"loading":true} → то {"disabled":true}

Ограничения и источник
  • Docara выводит элемент управления, но не привязывает прикладные данные и не выполняет действие.
  • Для перехода следует использовать обычную ссылку или docara.cta.
  • Мост серверных событий Larena намеренно исключён: переносимая Docara выводит компонент без серверных обработчиков.
