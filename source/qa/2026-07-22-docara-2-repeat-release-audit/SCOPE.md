# Границы

## Включено

- репозиторий Docara в текущем worktree;
- Composer package и portable starter;
- generated documentation site;
- локальный `docara.test` только как дополнительное наблюдение, если он
  соответствует exact target;
- canonical и активный установленный skill как часть пользовательского пути;
- локальный workflow/process control.

## Исключено

- исправление обнаруженных проблем;
- GitHub push/PR/merge;
- release tag, Packagist/package publication;
- production deployment;
- полная WCAG-сертификация, penetration test и нагрузочное тестирование.
