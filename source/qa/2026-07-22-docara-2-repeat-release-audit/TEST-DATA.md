# Тестовые данные

- Все проекты создаются в уникальных каталогах `/tmp`.
- Проверка update использует искусственно добавленные пользовательские Markdown,
  JSON-настройки и branding assets.
- Browser QA использует только сборку exact target.
- Секреты, персональные данные и production data не используются.
