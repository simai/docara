# Scope matrix

| Prototype group | Expected public form | Audit status |
|---|---|---|
| Inline primitives | Native Markdown or compact Docara inline component | accepted |
| Documentation blocks | Native Markdown or Docara block component | accepted |
| Publishing blocks | Native/generated capability or Docara block component | accepted |
| Layout and actions | Composable grid/card/button/icon primitives | accepted |
| Landing blocks | Distinct semantic Docara blocks | accepted |
| Advanced escape hatches | Explicit safe syntax and documented boundary | accepted |

The row-level evidence and public disposition for every prototype scenario are
recorded in `FINDINGS.md`. The accepted public catalog contains 30 preferred
components/capabilities; obsolete aliases are intentionally excluded.
