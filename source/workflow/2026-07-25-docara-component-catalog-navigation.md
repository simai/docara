# Каталог компонентов: простой список и навигация

## Цель

Сделать каталог компонентов Docara простым обозревателем без локального
фильтра: одна карточка в строке, отдельная страница для каждого поддерживаемого
компонента и доступ к этим страницам через левое меню.

## Границы

- Глобальный поиск сайта в шапке не меняется.
- Из каталога удаляется только локальная форма поиска и фильтрации.
- Поддерживаемые компоненты получают пункты навигации.
- Неподдерживаемые записи остаются пояснениями в каталоге и не создают битых
  ссылок в меню.

## Приёмка

- На `/ru/components/catalog/` отсутствует локальная форма поиска.
- Карточки компонентов располагаются по одной в строке.
- Все сгенерированные страницы поддерживаемых компонентов доступны в левом
  меню.
- Настройка `navigation.hidden` раздела по-прежнему может скрыть всю ветку.
- Сборка, PHPUnit, статическая проверка и браузерная проверка проходят.
