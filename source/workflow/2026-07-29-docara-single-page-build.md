# Docara single-page build

## Goal

Исправить иконку копирования в компоненте `docara.example` и добавить безопасную
пересборку одной существующей страницы по её публичному URL без рендеринга всей
документации.

## Contract

- Полная сборка остаётся исходной операцией и создаёт весь статический сайт.
- `build --page=/route/` разрешён только после полной сборки того же environment.
- Одностраничная сборка заново планирует сайт, навигацию и поиск, но рендерит
  только выбранный HTML-файл и атомарно обновляет существующий build-каталог.
- Для новых, удалённых и переименованных страниц, структуры меню, общих настроек
  и Framework lock требуется полная сборка.
- Селектор страницы — публичный URL. Поэтому один механизм работает и с
  Markdown-страницами, и с generated component pages.

## Done when

- кнопка копирования использует официальный `sf-icon`;
- команда принимает `--page` и fail-closed обрабатывает отсутствующую сборку и
  неизвестный URL;
- соседние HTML-страницы при точечной сборке остаются byte-identical;
- поисковый индекс и diagnostics остаются полными;
- документация CLI содержит короткий сценарий использования;
- PHPUnit, static verification и `git diff --check` проходят.
