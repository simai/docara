# Docara product homepage brief

Date: 2026-07-24

## Product truth

Docara builds static documentation, references and compact product pages from
Markdown content and validated JSON configuration. The authoring path requires
PHP and Composer, while the published output is static. Presentation uses
SIMAI Framework with immutable revisions recorded in the project.

Verified capabilities used on the homepage:

- Markdown pages and typed component directives;
- site, section and page configuration with inheritance;
- documentation and landing presentation presets;
- multilevel navigation, breadcrumbs, local search, page outline and
  previous/next links for documentation;
- responsive light and dark themes;
- arbitrary declared locales, with RTL enabled explicitly;
- generated component catalog tied to the exact build;
- static verification and documented staging, smoke and rollback flow;
- resolved page plans that explain effective configuration.

## Audiences

1. Product or technical owner evaluating fit.
2. Author who wants to create the first site.
3. Developer who needs exact architecture, component and verification details.

## Positioning

Docara is a focused static site generator for teams that want readable
Markdown content, declarative JSON composition and a consistent SIMAI
Framework interface without maintaining a separate frontend toolchain in the
authoring project.

## Message hierarchy

1. Create documentation and product pages from Markdown and JSON.
2. Keep content, composition and presentation concerns explicit.
3. Give readers a complete documentation experience.
4. Build, inspect and verify a deterministic static result.
5. Extend through typed components and an exact component catalog.

## Conversion

- primary action: start from an empty directory;
- secondary action: inspect the component catalog;
- proof action: explore the live documentation structure.

No analytics contract exists in the current static product. This workflow does
not invent conversion metrics or introduce tracking.

## Boundaries

- no customer logos or adoption claims;
- no unsupported performance comparison;
- no promise of complete offline runtime, every Framework component or public
  release readiness;
- local search is prefix-oriented, not morphological, typo-tolerant or AI
  search;
- Node.js is excluded from the author project path, not from maintenance of
  Docara's own source assets.
