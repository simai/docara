## Source boundaries and retained compatibility

The current Russian public build does not read page prose from
`resources/language-packs`, `resources/i18n` or `site.json`. The Russian package
language pack has zero public messages. Shared visible labels are owned by
`docs/site/content/ru/lang.json`.

`LanguagePackRepository`, `InlineComponentRenderer`, the declarative parser
and Framework integration remain only where they are package-owned input
validation, composition or non-public compatibility APIs. They do not own or
bypass a public Russian page. Other-locale package data is deliberately
retained and is not called migrated.
