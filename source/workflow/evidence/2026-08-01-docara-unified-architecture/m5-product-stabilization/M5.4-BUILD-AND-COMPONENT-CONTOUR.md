# M5.4 build provenance, atomic partial build and component contour

Status: PASS

Candidate parent: `546c7b7f3d1d566e7242ea31756c095e22a89875`

## User-visible result

A full or isolated build now records enough safe provenance to identify the
exact Markdown/config inputs, in-memory Document IR, component runtime, Docara
engine tree, dependency tuple, Framework lock/manifests/assets, publisher
templates/runtime assets, effective catalogue and locale UI source. No private
absolute path is serialized.

An isolated build is refused when its complete base was produced by a different
engine/dependency tuple. A selected-page compile error leaves the complete
accepted output byte-for-byte unchanged, including search, navigation,
backlinks, catalogue and receipts.

## Component and source-boundary audit

- `ComponentNode` and `ComponentBlockNode` implement one
  `ComponentContractNode` typed contract;
- inline and block adapters both call only
  `SmartComponentGateway::renderComponentContract()`;
- aliases remain registry-owned, props/slots are validated by the shared
  content component renderer before its trusted template;
- `ui.*` and `docara.*` plan resolution remains behind the same
  `SmartComponentGateway` facade;
- the public builder constructs the translator in content-only, no-fallback
  mode and does not instantiate `LanguagePackRepository`;
- a malformed project `resources/language-packs/ru.json` is ignored by the
  public build, while a declared locale missing its own
  `content/<locale>/lang.json` UI messages fails instead of silently borrowing
  another locale;
- package language packs and component examples remain package-owned
  compatibility/demo inputs, not public page prose owners;
- typed Document IR remains in memory. The receipt stores hashes and counts,
  not a mandatory page IR serialization.

The package declarative AST/renderer remains the admitted shell composition API
and is not a second Markdown publication owner. `InlineComponentRenderer` is a
syntax adapter into the same typed contract/gateway, not a component-specific
renderer registry.
