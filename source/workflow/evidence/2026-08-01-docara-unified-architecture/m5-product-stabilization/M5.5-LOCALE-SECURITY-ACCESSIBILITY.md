# M5.5 locale, security and accessibility fixture

Status: PASS

Candidate parent: `936d524dc23d902bdee9eaaf94e1627bbb04c5a1`

## User-visible result

Docara now has a physical minimal English LTR site and Arabic RTL site that
exercise the same Markdown owner, `content/<locale>/lang.json`, PageBuilder,
search, navigation and renderer pipeline as Russian pages. They are product
fixtures, not a claim that the public documentation has been translated.

Raw authored HTML fails closed with a safe file, line and column. The explicit
`html` directive remains sandboxed. Embeds accept only the declared same-origin
or HTTPS provider policy; unsupported hosts, schemes and consent combinations
fail before publication.

## Discrepancies and decisions

The first raw-HTML guard treated HTML inside custom directive bodies and a
short fence inside a longer fence as top-level authored HTML. It also rechecked
trusted internal reference markup during recursive rendering. The correction
checks the authored document once, respects exact fence lengths, leaves typed
directive bodies to their own validators and keeps CommonMark configured to
strip HTML there. A legacy test that expected opaque raw HTML to hide later
directives was replaced by the required fail-closed assertion.
