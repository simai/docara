## Outcome

The bundled registry is compiled by deterministic provider-root discovery.
`docara.package` owns `docara.*`; source-pinned `framework.lock` owns `ui.*`.
All six built-ins carry the normalized SF5 v1 manifest contract. The existing
Gateway resolves the component definition first and dispatches by its provider
ID; it contains no namespace or component-ID branch.

`SmartContribution` surfaces were deleted after parity. The bounded
`LegacyBundledSmartProvider` is the explicit removal adapter for the six
repository-owned pre-portable directory layouts; new project/package artifacts
use the portable filesystem provider directly.
