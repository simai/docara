# G1.5 — Project-local portable Smart

Parent SHA: `4608645`

## Outcome

A project opts in with one declarative field:

```json
{"smart":{"namespace":"project"}}
```

The artifact root is fixed to `smart/`; authored Markdown/config cannot select a
PHP or template path. `ProjectSmartProvider` validates namespace ownership,
paths, symlinks, manifest/view/preset/template/assets and compiles the artifact
into the same `SmartRegistry`. Dotted Smart directives compile to a typed
`SmartComponentNode` in memory and render through the existing
`DocumentRendererRegistry`, `SmartComponentGateway` and `SmartRenderer`.

The initialized starter now contains `smart/project.notice` and invokes it from
one Markdown page. No component registration or identity branch was added
under `src/`; the runtime only knows the provider contract.
