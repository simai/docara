- `/private/tmp/docara-r1-candidate-a.53PUwa/repo`;
- `/private/tmp/docara-r1-candidate-b.5O8m7V/repo`.

In each clone:

```bash
php scripts/build-release-package.php --version=2.0.0-rc.1 --tag=v2.0.0-rc.1 --output-dir=<output>
php scripts/verify-release-package.php <zip> <release-manifest> <checksums>
```

`cmp` reports byte identity for ZIP, release manifest and checksum file.
Verification reads the artifact, not the developer tree. It checks per-file
hashes, required files, forbidden surfaces, traversal, duplicate and
case-colliding names, normalized 1980 timestamps, executable mode only for
`docara`, regular-file modes for all other entries and absence of symlinks.

The positive package surface is owned by
`resources/release/package-surface.json`. Graph, workflow evidence, tests,
VCS/CI metadata, caches, credentials and `vendor/` are excluded. The archive
contains `RELEASE-MANIFEST.json` and CycloneDX
`RELEASE-SBOM.cdx.json`; the archive hash is deliberately paired externally to
avoid a self-referential manifest.
