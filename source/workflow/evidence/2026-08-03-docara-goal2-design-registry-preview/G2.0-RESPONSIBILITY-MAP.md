## Ownership and precedence contract

1. Project provider reads only `<project>/design/{layouts,views,sections,blocks}`
   and may own only the namespace declared by `project.namespace`.
2. Explicit package providers have unique declared namespaces.
3. Built-in Docara provider owns `docara.*`, `layout.docara.*`,
   `section.docara.*` and package block IDs.
4. Duplicate canonical IDs, aliases or ownership claims fail closed; priority
   never permits implicit shadowing.
5. Paths are provider-relative JSON files beneath a fixed admitted root;
   absolute paths, traversal, symlinks and executable path fields are denied.
6. Source hash, provider ID/revision and root-relative path form provenance.

## Preserved safety boundary

View Trees remain a bounded structural language: known node kinds, safe HTML
tags, safe attributes, registered utilities and descriptor-declared regions or
slots only. Design config cannot supply PHP, callback, Blade/template path,
raw HTML, arbitrary CSS/JS or remote input.
