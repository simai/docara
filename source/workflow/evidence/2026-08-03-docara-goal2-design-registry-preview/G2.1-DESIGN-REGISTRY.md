# G2.1 — Design Registry contract

Date: 2026-08-03
Parent: `a874072`
Status: `PASS`

Implemented one typed registry contour:

```text
DesignArtifactProvider -> DesignArtifactDescriptor -> DesignRegistry
```

Built-in and project providers use fixed admitted roots. Provider priority is
only a deterministic ordering mechanism: namespace collision and duplicate
provider/artifact identity fail closed, so there is no implicit shadowing.
Project definitions may own only their declared non-reserved namespace.

Every descriptor contains kind, canonical ID, owner namespace, provider,
provider revision, root-relative path, SHA-256, validated definition and
provenance. The registry fingerprint is deterministic.
