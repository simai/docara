## Outcome

The repository-owned evidence runner reads exact PHP-generated QA plans and
serves each isolated `.docara-preview/output/<target>` tree. It does not render,
compose or compile content. All HTML/assets therefore remain products of the
accepted PreviewKernel, PageBuilder, DesignRegistry and Smart gateway path.

Every Smart, region and layout subject passed desktop 1440x900 and mobile
390x844, light/dark and LTR/RTL: 24 scenarios total. All local responses were
200; a11y, console errors/warnings, horizontal overflow and immediate visual
diff were zero; keyboard focus/Esc and reduced-motion checks passed.

The first run found duplicate runtime dialog IDs because the Docara `<sf-modal>`
host and SF5-generated dialog both owned the same `id`. The bounded correction
keeps `modal-id` as the Framework contract and removes the duplicate host `id`
from search and preferences templates. A permanent source regression protects
both templates. No Framework source was changed.
