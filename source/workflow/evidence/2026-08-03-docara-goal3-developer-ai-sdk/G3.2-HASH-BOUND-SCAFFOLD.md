# G3.2 — hash-bound scaffold

Candidate commit: `7f9f9fb`.

`scaffold smart|design <project.id> --dry-run --json` persists a deterministic
plan. `--apply=<sha256>` rechecks project/config/target/content hashes and writes
only new `smart/` or `design/` trees. Stale/tampered plans, traversal, symlink,
hardlink, duplicate namespace/target, generated, lock, engine and external
roots fail closed; partial writes roll back.

Focused proof: `ScaffoldServiceTest`. The produced Smart uses the accepted
portable array ABI, and both Smart/design output reload through the production
registries and are immediately validate/preview ready. Rollback: revert
`7f9f9fb`; scaffold test writes exist only in disposable fixtures.
