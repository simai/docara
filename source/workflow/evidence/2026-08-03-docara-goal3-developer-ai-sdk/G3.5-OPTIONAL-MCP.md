# G3.5 — optional local MCP

Candidate commits: `e15a2ae`, `66ab32b`, `85e2231`.

`tools/mcp-docara/server.php` is an optional PHP stdio adapter over the same
`SdkService`. It exposes discovery, plan/apply, validate/test and QA tools; it
cannot accept a caller root/path, is read-only by default and requires both the
process write capability and exact persisted plan for apply. It is shipped in
the package but is neither a Composer bin nor a normal runtime dependency.

`McpAdapterTest` covers capability and delegation boundaries. A fresh dist
consumer executed initialize, tools/list and `docara_doctor`; the structured
result remained `docara.operation_result.v1` and bound engine revision
`fface98a8d5fc572b0f2b30e58049981fa9fad3a`.
