# C1.3 — executable CLI, JSON and MCP journey

Published commands now match the real Symfony Console contract:

- `docara preview smart --page=<route> --selector=<Smart ID>`;
- scaffold preview is `--dry-run --json`;
- apply accepts only `--apply=<exact-plan-sha256>`;
- the exact hash is read from the dry-run result before apply;
- validate/test use the same application services and admitted Smart ID.

`GoalCExecutableJourneyTest` initializes a disposable project and executes the
documented discover -> plan -> preview -> dry-run -> hash-bound apply ->
validate/test sequence. It also proves JSON and optional MCP read/write
boundaries, stale/unsafe input rejection and absence of external writes.
Invalid positional preview syntax and the nonexistent `--apply-plan` option are
permanent negative documentation checks.

The project-local example uses `project.agent-card`; the production preview and
test use admitted `ui.dropdown` on `/ru/project-demos/`. No arbitrary PHP,
template or filesystem path is accepted.
