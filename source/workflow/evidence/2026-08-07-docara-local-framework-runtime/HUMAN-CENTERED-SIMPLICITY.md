# Human-centered simplicity review

The visible interface was not redesigned. One local, hash-bound Framework
projection replaces unreliable CDN runtime URLs while preserving the existing
HTML, typography and component behavior. Users no longer need a reload for
icons to appear; authors and consumers need no Node.js step.

The 117-file closure is the smallest honest current-project closure that also
covers lazy theme loading and every authored highlight language. A manifest
and one repository boundary carry the necessary security complexity. There is
no fallback CDN, duplicate asset planner or second component runtime.
