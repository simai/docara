Будущая библиотека компонентов Docara

Одна страница показывает рекомендуемый публичный язык Markdown-компонентов и основные варианты. Внутри используются токены, утилиты и готовые элементы SIMAI Framework; новые композиции пока помечены как прототип.

Главное правило: автор выбирает смысл компонента, а не технический пакет. Ширина задаётся родительской сеткой, поэтому не нужны имена вроде card-1/4.

Button

Строчное действие: может находиться внутри композиции или отдельно на строке.

Композиция: несколько кнопок размещает родительский контейнер действий. Сама кнопка не создаёт секцию и не управляет шириной строки.

Код, данные и связи

Практические сценарии, без которых документация остаётся набором отдельных страниц: воспроизводимые примеры, таблицы, источники, сведения о странице и связи между материалами.

Демонстрация с исходником

Результат и код занимают одну область. Вкладка в шапке переключает содержимое, поэтому пример остаётся просторным на любом экране.

Демо · Markdown
Новая версия Рекомендуется Необязательно 
:badge[Новая версия]{type=main scheme=primary}
:badge[Рекомендуется]{type=tonal scheme=primary}
:badge[Необязательно]{type=outline scheme=on-surface}

Один источник истины. Вкладка «Демо» показывает результат, а соседняя вкладка получает название языка исходника: Markdown, HTML, CSS, JSON или другой поддерживаемый формат. Кнопка копирования появляется только рядом с кодом.

У обычной страницы нет пакета, surface и возможностей компонента, поэтому интерфейс не показывает лишние бейджи.

update Обновлено 26 июля 2026 person Команда Docara Открыть исходник
Откуда берутся сведения 
{
  "package":     "simai-framework.lock.json",
  "owner":       "component manifest",
  "capabilities":"component registry",
  "updated":     "Git history",
  "revision":    "Git commit",
  "override":    "<page>.page.json — только если значение нельзя вычислить"
}

Главное различие: maintainer — постоянный ответственный из manifest, а last_changed_by — последний автор изменения из Git. Эти значения не подменяют друг друга. Во время сборки Docara нормализует источники в один generated metadata index; автор страницы ничего не дублирует вручную.

Контролируемое расширение

Заголовки и высота строки

Нативные Markdown-заголовки используют типографику текущего SIMAI Framework без локальной подмены line-height.

# H1 … ###### H6
h1

Заголовок первого уровня

h2

Заголовок второго уровня

h3

Заголовок третьего уровня

h4

Заголовок четвёртого уровня

В текущем исходнике Framework применяются пары --sf-text-size-* и --sf-title-height-*. Таблица с --sf-heading-N--line-height относится к прежнему контракту; локальный CSS Docara не должен его имитировать.

HTML

Явный escape hatch для доверенного содержимого, когда готового компонента недостаточно.

:::html
<aside aria-label="Статус">
  Собственный HTML
</aside>
Не компонент по умолчанию.

Нужны режим доверия, политика sanitization и явное предупреждение сборщика. Для повторяемого интерфейса следует создать обычный компонент.
