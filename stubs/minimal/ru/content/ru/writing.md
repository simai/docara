# Как писать страницы

Страницы пишутся на обычном Markdown. Первый заголовок — название страницы,
заголовки второго и третьего уровня образуют содержание справа.

## Текст и списки

Используйте **полужирный**, *курсив*, `код в строке` и [ссылки](../).

1. Нумерованный список сохраняет порядок.
2. Вложенные списки тоже работают:
   - пункт;
   - ещё один пункт.

> Цитата выделяется на фоне текста.

## Живой пример

Блок `:::example` показывает результат рядом с его точным исходником.

:::example {label="Пример"}
```markdown
:badge[Готово]{variant=main scheme=success size=1/2}
```
:::
