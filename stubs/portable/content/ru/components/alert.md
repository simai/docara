# Уведомление

Уведомление сообщает важную информацию, результат, предупреждение или ошибку.

## Общий пример

:::example {label="Общий пример"}
```markdown
:::alert {type=info variant=default}
#### Полезная информация

Продолжайте работу в обычном порядке.
:::
```
:::

```markdown
:::alert {type=info variant=default}
#### Полезная информация

Продолжайте работу в обычном порядке.
:::
```

## Типы

Параметр `type` принимает значения `clear`, `info`, `success`, `warning` и
`danger`. По умолчанию используется `info`.

:::alert {type=clear}
#### К сведению

Это сообщение не требует действия.
:::

:::alert {type=success}
#### Готово

Сборка успешно прошла проверку.
:::

:::alert {type=warning variant=outlined}
#### Обратите внимание

Проверьте параметры перед публикацией.
:::

:::alert {type=danger variant=flat}
#### Требуется исправление

Конфигурация не прошла проверку.
:::

## Оформление

Параметр `variant` принимает значения `default`, `flat` и `outlined`. Заголовок
и пояснение должны передавать смысл без опоры только на цвет.
