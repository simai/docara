# Баннер

Баннер показывает короткое объявление, которое относится ко всей странице:
например, к версии документации, сроку действия или важному изменению.

## Общий пример

:::example {label="Общий пример"}
```markdown
:::banner {type=info}
Эта версия документации относится к текущей стабильной сборке.
:::
```
:::

## Смысл сообщения

Параметр `type` задаёт смысл и оформление баннера.

| Значение | Результат |
| --- | --- |
| `info` | Нейтральная информация · **По умолчанию** |
| `success` | Успешное изменение |
| `warning` | Предупреждение перед действием |
| `danger` | Существенный риск или недоступность |

:::banner {type=success}
Документация обновлена до текущей стабильной версии.
:::

:::banner {type=warning}
Перед обновлением сохраните текущую сборку.
:::

:::banner {type=danger}
Эта версия больше не получает исправления безопасности.
:::

## Вызов

```markdown
:::banner {type=warning}
Перед обновлением сохраните текущую сборку.
:::
```

Пишите коротко и называйте последствие или следующее действие. Если сообщение
относится к отдельному шагу внутри статьи, используйте уведомление, а не баннер.
