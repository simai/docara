# Сноски и источники

Сноска связывает утверждение с проверяемым пояснением или источником.

## Общий пример

:::example {label="Общий пример"}
```markdown
Docara читает Markdown.[^source]

[^source]: Руководство проекта и адрес публикации.
```
:::

## Вызов

```markdown
Утверждение.[^note]

[^note]: Автор, название и ссылка.
```

Используйте устойчивую метку и оставляйте читателю достаточно данных для
проверки источника.
