# Заголовки и текст

Заголовки делят статью на понятные разделы, а обычный Markdown выделяет
важные слова без ручной HTML-разметки.

## Общий пример

:::example {label="Общий пример"}
```markdown
## Настройка проекта

Сначала укажите **обязательные параметры**, затем добавьте *полезные пояснения*.
```
:::

## Вызов

```markdown
## Раздел

**Важный текст**, *акцент*, ~~устаревшая формулировка~~ и `параметр`.
```

Не пропускайте уровни заголовков ради размера и не заменяйте Markdown
произвольным HTML.
