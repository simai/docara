# Таблица Markdown

Таблица сравнивает объекты по одинаковым признакам и безопасно прокручивается
на узком экране.

## Общий пример

:::example {label="Общий пример"}
```markdown
| Файл | Роль |
| --- | --- |
| `docara.json` | Настройки сайта |
| `section.json` | Настройки раздела |
```
:::

## Вызов

```markdown
| Параметр | Значение |
| --- | --- |
| `theme` | `system` |
```

Для длинного содержимого используйте обычные разделы вместо сложной таблицы.
