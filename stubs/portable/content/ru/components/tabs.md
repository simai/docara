# Вкладки

Вкладки помещают несколько равноценных представлений в один компактный блок.
Читатель переключается между ними мышью или клавиатурой, не покидая страницу.

## Общий пример

:::example {label="Общий пример"}
````markdown
:::tabs
### Composer

```bash
composer create-project simai/docara my-docs
```

### Архив

Скачайте архив и распакуйте его в пустой каталог.

### Результат

Готовый сайт появится в каталоге сборки.
:::
````
:::

## Наглядные варианты

Внутри одной вкладки можно использовать обычный Markdown: текст, списки,
ссылки и код. Заголовок третьего уровня становится короткой подписью вкладки.

:::tabs
### Быстрый старт

1. Создайте проект.
2. Добавьте Markdown.
3. Запустите сборку.

### Проверка

```bash
php vendor/bin/docara verify-static build_production
```

### Публикация

Передавайте на сервер только проверенный каталог сборки.
:::

Первая вкладка выбрана при открытии страницы. Стрелки влево и вправо меняют
вкладку, `Home` переводит на первую, `End` — на последнюю; фокус следует за
выбором.

## Вызов

```markdown
:::tabs
### Linux

Команда для Linux.

### macOS

Команда для macOS.
:::
```

Нужно не менее двух вкладок, и у каждой должны быть заголовок `###` и
содержимое. Используйте этот блок для альтернатив одного уровня. Шаги процесса
лучше оставлять обычным списком или оформлять блоком Steps.
