# Компоненты проекта

Эти примеры лежат в каталоге `smart/` самого проекта и подключаются без изменения движка Docara.

## Команда установки

Компонент только формирует и копирует команду. Он ничего не запускает.

:::project.install-builder
{"title":"Соберите команду установки","package":"simai/docara","version":"^2.0"}
:::

## Конфигуратор продукта

Расчёт выполняется только в браузере. Демо не отправляет данные и не создаёт заказ.

:::project.product-configurator
{"title":"Настройте пример продукта","base_price":2500,"currency":"₽"}
:::
