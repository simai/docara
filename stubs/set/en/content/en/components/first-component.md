# First component

Say in one or two sentences what the component does and when to use it.
This page is a sample: rename the file after the component's folder and
replace the text. The sections below come in the order a reader looks for
them: an example first, then parameters and events.

## Example

Show the component at work. A live example is an `examples/<id>/` folder
with `index.html` and `index.js`, shown with `:::example {id="<id>" label="…"}`.

```html
<sf-{set}-example aria-label="Example"></sf-{set}-example>
```

## Parameters

| Parameter | Type | Default | Description |
|:---|:---|:---|:---|
| `aria-label` | string | — | The component's accessible name. |
