# Components

Here is one page for each component of the `{set}` set. Every page has the
same parts: what it is, live examples, parameters, events and links to
related pages.

| Component | Page |
|:---|:---|
| First component | [First component](first-component/) |

## How to add a component page

1. Create `components/<component folder>.md`: the file name matches the
   component's folder in the set, so the page is easy to find by its tag.
2. Copy the sections of [First component](first-component/) into it and
   replace the text.
3. Add a row to the table above and to the table on the home page.

The `navigation.order` field in the `<name>.page.json` file next to a page
sets its place in the menu.
