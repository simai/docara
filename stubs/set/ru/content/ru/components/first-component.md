# Первый компонент

Опишите в одном-двух предложениях, что делает компонент и когда его брать.
Эта страница — образец: переименуйте файл по папке компонента и замените
текст. Разделы ниже идут в том порядке, в каком их ищет читатель: сначала
пример, потом параметры и события.

## Пример

Покажите компонент в деле. Живой пример — папка `examples/<id>/` с
`index.html` и `index.js` и блок `:::example {id="<id>" label="…"}`.

```html
<sf-{set}-example aria-label="Пример"></sf-{set}-example>
```

## Параметры

| Параметр | Тип | По умолчанию | Описание |
|:---|:---|:---|:---|
| `aria-label` | строка | — | Доступное имя компонента. |

## События

| Событие | Когда приходит |
|:---|:---|
| `change` | Опишите, что изменилось. |
