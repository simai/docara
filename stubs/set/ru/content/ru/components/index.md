# Компоненты

Здесь по странице на каждый компонент набора `{set}`. Каждая страница
устроена одинаково: что это, живые примеры, параметры, события и ссылки на
связанные страницы.

| Компонент | Страница |
|:---|:---|
| Первый компонент | [Первый компонент](first-component/) |

## Как добавить страницу компонента

1. Создайте файл `components/<папка компонента>.md`: имя файла совпадает с
   папкой компонента в наборе, так страницу легко найти по тегу.
2. Скопируйте в него разделы страницы [Первый компонент](first-component/)
   и замените текст.
3. Добавьте строку в таблицу выше и в таблицу на главной странице.

Порядок страниц в меню задаёт поле `navigation.order` в файле
`<имя>.page.json` рядом со страницей.
