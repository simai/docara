# Подключение

Страница подключает SIMAI Framework и называет наборы, которые использует.
Loader сам находит набор, загружает его правила и подгружает только те
компоненты, которые есть на странице.

## Одна строка

```html
<script src="https://cdn.jsdelivr.net/npm/@simai-studio/ui/distr/core/js/core.min.js" data-sf-sets="{set}"></script>
```

Атрибут `data-sf-sets` перечисляет наборы через пробел. Конкретную версию
набора задают через `@`, например `data-sf-sets="{set}@1.0.0"`. Без версии
Loader выбирает самый новый выпуск набора, который подходит к подключённому
Core. Для рабочего сайта закрепите и версию Framework в адресе, и версию
набора.

## Из своей копии

Если страница раздаёт сборку набора сама, она указывает адрес до запуска
Core:

```html
<script>
  window.SF_BOOT_CONFIG = {
    packages: {
      '{set}': {base: '/assets/{set}/smart', version: '1.0.0'}
    }
  };
</script>
<script src="/assets/ui/distr/core/js/core.min.js"></script>
```

`base` — папка `smart/` сборки набора: в ней лежат `rule.js` и папки
компонентов.

## Версии и совместимость

Замените строку таблицы выпусками своего набора, новые сверху.

| Набор | Собран над SIMAI Framework | Нужен Core |
|:---|:---|:---|
| 1.0.0 | выпуск Framework, над которым собран набор | наименьшая версия `core.runtime` |
