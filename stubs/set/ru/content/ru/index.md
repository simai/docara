# Набор {set}

Компоненты набора `{set}` для SIMAI Framework: подключаются одной строкой
рядом с Framework и работают на любой странице.

[Подключить](connection/)

[Компоненты](components/)
:::

## Что входит в набор

Замените эту таблицу компонентами своего набора: по строке на компонент,
со ссылкой на его страницу.

| Компонент | Что делает |
|:---|:---|
| [Первый компонент](components/first-component/) | Опишите одной строкой, что он делает. |

## Лицензия

Укажите лицензию набора и коротко, кому и на каких условиях можно им
пользоваться. Полный текст лицензии лежит в файле `LICENSE.md` репозитория
набора.

## Совместимость с SIMAI Framework

Каждый выпуск набора собран и проверен над одним выпуском SIMAI Framework и
называет наименьший Core, с которым работает. Таблица выпусков — в разделе
[Подключение](connection/#версии-и-совместимость).

## С чего начать

1. [Подключите набор](connection/) одной строкой рядом с SIMAI Framework.
2. Откройте страницу [компонента](components/) и скопируйте пример.
3. Посмотрите [демо](demos/): готовые экраны из компонентов набора.
4. Что изменилось в последних выпусках, смотрите в разделе [Изменения](changes/).
