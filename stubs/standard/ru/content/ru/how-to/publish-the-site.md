# Опубликуйте сайт

Эта инструкция нужна, когда страницы готовы и сайт пора выложить.
Замените её задачами, которые ваши читатели решают чаще всего.

## Перед началом

- На страницах, которые нужно опубликовать, нет строки `draft: true`.

## Шаги

1. Соберите сайт: `php vendor/bin/docara build production`.
2. Проверьте результат: `php vendor/bin/docara verify-static build_production`.
3. Скопируйте папку `build_production/` на любой статический хостинг.

## Результат

Сайт открывается по адресу хостинга, ссылки и поиск работают.
