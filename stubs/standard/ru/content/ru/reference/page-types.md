# Типы страниц

У каждой страницы один тип. `docara validate page` проверяет, что на странице
есть части, нужные её типу. Замените эту страницу справочником для ваших читателей.

## Типы

| Тип | Для чего | Обязательные части |
| --- | --- | --- |
| `landing` | Вход в раздел, ведёт читателя дальше | Заголовок, вступление, два раздела, ссылка |
| `article` | Страница, которой не подошёл другой тип | Заголовок, вступление, раздел |
| `tutorial` | Первый урок с проводником | Заголовок, нумерованные шаги |
| `how_to` | Шаги одной практической задачи | Заголовок, нумерованные шаги |
| `reference` | Точные сведения для поиска | Заголовок, вступление, таблица или список |
| `explanation` | Причины, устройство и ограничения | Заголовок, вступление, раздел |

## Front matter

| Поле | Что задаёт |
| --- | --- |
| `title` | Название страницы в меню и во вкладке браузера. |
| `description` | Одно предложение для поиска и превью ссылки. |
| `profile` | Тип страницы. |
| `draft` | `true` не пускает страницу в сборку. |
